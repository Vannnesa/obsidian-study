# Displaying Files
# 显示文件

既然我们已经掌握了目录的基础知识，接下来我们将学习一些用于操作**常规文件**的实用命令。我们将从显示文件内容的命令开始：`cat`、`more`、`less`、`head` 和 `tail`。

其中第一个是 `cat`，它读取一个或多个文件，将它们**连接**在一起（这也是它名字的由来），然后打印出来。你可能已经猜到，`cat` 根据其**命令行参数**决定读取和打印哪些文件。它会按照你命名文件的顺序，打印出你指定的每个文件。

如果你不给 `cat` 任何命令行参数，那么它会读取**标准输入**（standard input）并打印出来。通常，标准输入是你运行程序的终端的输入——也就是说，它通常就是你输入的内容。如果你不带参数直接运行 `cat`，这意味着它会把你输入的内容回显出来。虽然这听起来有点没用，但当**标准输入**或**标准输出**（它打印的地方：通常是终端屏幕）被**重定向**或**管道**到其他地方时，它会变得更有用。

虽然你可以用 `cat` 显示文件内容，但通常你会想要比仅仅打印文件多一点功能。`more` 命令显示一屏内容，然后等待你按一个键，再显示下一屏。它的名字来源于它会提示 `---More--`，表示你应该按一个键来查看更多文本。`less` 命令取代了 `more`，并提供了更多功能：你可以用方向键上下滚动，并搜索文本。许多系统实际上在你请求 `more` 时运行的是 `less`。

还有一些命令只显示文件的开头（`head`）或结尾（`tail`）。这些命令都可以接受一个参数，指定从所请求文件中显示多少行。当然，要了解这些命令的完整细节，请查看它们的 **man 页面**。

注意，这些命令只是让你**查看**文件内容。

## Moving, Copying, and Deleting
## 移动、复制和删除

你可能希望执行的另一项任务是**移动**（`mv`）、**复制**（`cp`）或**删除**（`rm`——代表“remove”）文件。前两个命令按顺序接受一个**源**和一个**目标**。也就是说，从哪里移动（或复制）文件，然后移动（或复制）到哪里。如果你给这两个命令超过 2 个参数，它们会假定前 N-1 个是源，最后一个是目标，而目标必须是一个目录。在这种情况下，每个源都会被移动（或复制）到那个目录中，并保留其原始文件名。

`rm` 命令接受任意数量的参数，并删除你指定的每个文件。如果你想删除一个目录，可以改用 `rmdir` 命令。如果你使用 `rmdir`，该目录必须是**空的**——它必须不包含任何文件或子目录（除了 `.` 和 `..`）。你也可以使用 `rm` 并给它 `-r` 选项，来**递归删除**目录中包含的所有文件和目录。使用 `rm` 时要小心：**一旦你删除了某些东西，它就没了**。

## Pattern Expansion: Globbing and Braces
## 模式扩展：通配符扩展和大括号扩展

你可能（经常）会发现自己希望一次性操作许多符合某种模式的文件——例如，删除所有文件名以 `~` 结尾的文件（编辑器通常在你编辑时通过给文件名追加 `~` 来创建备份文件）。你可能有很多这样的文件，逐个输入它们的名字会很繁琐。

因为这些名字遵循某种模式，你可以使用 **globbing**（通配符扩展）——即根据当前目录中的文件名扩展为多个参数的模式——来简洁地描述它们。在这个特定情况下，你可以执行 `rm *~`（注意 `*` 和 `~` 之间没有空格；如果执行 `rm * ~`，会把 `*` 扩展为目录中的所有文件，然后 `~` 会作为它们之后的一个单独参数）。这里，`*` 是一个模式，意思是“**匹配任何内容**”。整个模式 `*~` 匹配（当前目录中）任何以 `~` 结尾的文件名。shell 会在把命令行参数传递给 `rm` 之前扩展这个 glob——也就是说，它会用适当匹配的名字替换 `*~`，而 `rm` 会看到所有这些名字作为它的命令行参数。

除了 `*` 之外，还有一些其他的 UNIX globbing 模式。其中之一是 `?`，它匹配**任意一个字符**。相比之下，`*` 匹配**任意数量**（包括 0 个）的字符。你还可以用 `[...]` 指定要匹配的某个字符集，或用 `[!...]` 排除某些字符。例如，如果你使用模式 `file0[123].txt`，它会匹配 `file01.txt`、`file02.txt` 和 `file03.txt`。如果你使用 `file0[!123].txt`，那么它不会匹配这些名字，但会匹配像 `file09.txt`、`file0x.txt` 或 `file0..txt` 这样的名字（以及许多其他名字）。

有时，你可能希望**按字面意思**使用这些特殊字符之一——也就是说，你可能希望 `*` 就表示字符 `*` 本身。在这种情况下，你可以**转义**该字符，以移除它的特殊含义。例如，`rm \*` 会准确删除名为 `*` 的文件，而 `rm *` 会删除当前目录中的所有文件。
