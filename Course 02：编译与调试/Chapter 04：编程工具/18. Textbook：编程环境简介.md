# Introduction to the Programming Environment
# 编程环境简介

在本课程以及本专项课程（specialization）的其余课程中，你将在为本专项课程**定制**的环境中编写编程作业，我们将其称为**实践编程环境**（Practice Programming Environment，简称 **PPE**）。这将使你能够像专业人士一样在环境中编写代码，但你**不需要**在你用于本课程的机器上下载或安装任何东西。

每当课程中你的位置有作业要做时，你都会有一篇标题为 **“Assignment [assignment ID]”** 的阅读材料，你可以通过该项打开实践编程环境。这会将你带到一个定制的 `xterm.js` 实例，这是一个你可以在浏览器中使用的**终端**！

你为本课程所做的所有内容都会保存在这个环境中的**主目录**（home directory）里，但如果你愿意，也可以下载它。

如果这看起来是新的，别担心——我们将在下一课中带你了解如何使用实践编程环境，并向你介绍你将用来成为优秀程序员的最重要的技术工具！
