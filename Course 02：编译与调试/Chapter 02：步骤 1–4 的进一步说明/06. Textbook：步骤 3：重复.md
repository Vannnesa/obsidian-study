# Generalizing Repetitions（泛化重复）

泛化算法的另一个重要部分是寻找相同（或相似）步骤的**重复**。当相似步骤重复时，你会希望根据步骤**重复多少次**（或**直到满足什么条件**）来泛化算法。为了考察泛化的这个方面，我们将暂时偏离矩形例子（它没有这种类型的重复），并考虑一个稍微不同的问题：

给定一个整数 `N`（>0），打印一个由 `*` 组成的直角三角形，高度为 `N`，底边为 `N`。

例如，如果 `N = 4`，你会打印：

```text
*
**
***
****
```

我们可能用 `N=5` 做一个例子，并得到**步骤 2**的以下结果：

```text
Print 1 star
Print a newline
Print 2 stars
Print a newline
Print 3 stars
Print a newline
Print 4 stars
Print a newline
Print 5 stars
Print a newline
```

这里，我们几乎在做同样的事情（`Print i stars; Print a newline`）5 次。一旦观察到重复，我们就可以通过这样重写算法，向泛化算法迈出一步：

```text
Count (call it i) from 1 to 5 (inclusive)
  Print i stars
  Print a newline
```

注意，我们这里重写算法的方式给了我们两个需要仔细审视的新常量：我们计数的范围中的 `1` 和 `5`。仔细考虑这些会表明，`1` 确实是常量（对于这个算法，我们总是从 1 开始计数），但 `5` 应该泛化为 `N`：

```text
Count (call it i) from 1 to N (inclusive)
  Print i stars
  Print a newline
```

这个算法对“星星三角形”问题正确。有时需要多花一点功夫，让你的算法步骤匹配起来，以便能用**重复**来描述它们。例如，考虑以下问题：

给定一个数字列表，求它们的和。

我们可能对数字列表 `3, 5, 42, 11` 做这个问题，并得到**步骤 2**的以下结果：

```text
Add 3  +  5 (= 8)
Add 8  + 42 (= 50)
Add 50 + 11 (= 61)
Your answer is 61
```

仔细审视这些常量中的每一个，可能会引导我们得到以下更一般的步骤：

```text
Add (the 1st number)      + (the 2nd number)
Add (the previous total)  + (the 3rd number)
Add (the previous total)  + (the 4th number)
Your answer is (the previous total)
```

这里，我们几乎——但还不完全——有了一个很好的重复模式。不过，我们可以让步骤匹配起来：

```text
previous_total = 0
previous_total = Add previous_total  + (the 1st number)
previous_total = Add previous_total  + (the 2nd number)
previous_total = Add previous_total  + (the 3rd number)
previous_total = Add previous_total  + (the 4th number)
Your answer is previous_total
```

注意，从数学上说，我们所做的是利用了 `0` 是**加法单位元**这一事实——对于任何数字 `N`，`0 + N = N`。我们还要注意，在对列表中的项进行数学运算之前，**先把单位元作为我们的答案**通常是个好主意，因为列表可能是空的。通常，对空列表进行数学运算时的正确答案是**你所执行运算的单位元**。也就是说，空数字列表的**和**是 `0`，空数字列表的**积**是 `1`（乘法单位元）。既然我们已经重新安排了步骤，就可以很好地泛化：

```text
previous_total = 0
Count (call it i) from 1 to how many numbers you have
   previous_total = Add previous_total  + (the ith number)
Your answer is previous_total
```

在这个例子中，我们还做了一件会让**步骤 5**（翻译成代码）更容易的事——**命名我们想要操作的值**。特别是，我们给计算的运行总和起了名字，这意味着不仅当我们说 `previous_total` 时，引用的是什么很清晰，而且当我们到达步骤 5 时，这会**直接翻译成一个变量**。
