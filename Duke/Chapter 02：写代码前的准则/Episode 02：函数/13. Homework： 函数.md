# 在开始之前：
本测验中的所有函数都**返回整数**，因此请以整数输入您的答案（例如，-8，而不是-8.0）。使用小数点可能会导致因答案格式不匹配而将正确答案标记为错误答案

问题1：

````c
int myFunction(int n) {
	int x = n * 2;
	int y = (x + 1) % 3;
	return y - x;
}
````
myFunction(4)的值是多少?

答案：
````spoiler
-8

````


问题2：

````c
int g (int x, int y) {
	x = x + y;
	int z = 2 * x - y;
	return z;
}
````
$\text{g(3, -10)}$的值是多少？

答案:
````spoiler
-4
````
