# Code Review
# 代码审查

另一种增加你对程序正确性信心的技术是**代码审查**（code review）。在代码审查中，另一位熟练的程序员审查你编写的代码，寻找你可能犯的错误。这样的审查是解决“**如何测试你没有想到的问题**”这一问题的另一种方式——审查者为代码带来**新鲜的视角**，可能会发现你没有考虑到的关注点。代码审查相对于其他形式的测试有一个很好的优势：通常当你的审查者发现问题时，她可以提出修复它的步骤。

代码审查的一种形式是**代码走查**（code walk-through），即程序员向审查者解释算法和代码。通常，审查者熟悉所需解决的问题和算法，因此走查侧重于代码本身。程序员逐行浏览代码，向审查者解释每一行做什么，以及为什么在那里。如果审查者不熟悉问题/算法，走查过程可能会从程序员带审查者了解编程过程的早期步骤开始——甚至可能从**步骤 1：自己动手做一个问题的实例**开始。
