***首先看到这里的同学不用播放视频了，接下来是Obsidian特供版grade使用教程。***


1. 首先克隆作业源文件的仓库(如果你还没有的话):
***请注意！该仓库内置DukeSolution仓库！无需重复下载。内容请翻阅到目录底部***
````bash
git clone https://github.com/Vannnesa/DukeSolution.git ~/DukeSolution
````


2. 安装Bun:(以下操作二选一)
- 前往[Bun](https://bun.sh)下载运行时依赖

- 或者如果你用Mac且安装了Homebrew:
````bash
brew install bun
````

3. 安装grade
````bash
cd ~/DukeSolution
bun src/index.ts install
````
即可完成安装

使用方法:

在任意目录新建文件夹 比如duke_homework
切换到该目录，然后使用`grade init` 生成作业目录
(init只在第一次使用 后续交作业只需要用grade即可评分)

更多grade操作请看DukeSolution的 [README](https://github.com/Vannnesa/DukeSolution)
