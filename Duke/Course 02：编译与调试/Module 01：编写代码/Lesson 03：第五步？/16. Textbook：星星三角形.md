# Stars Example
# 星星示例

既然我们已经看到了如何把泛化后的步骤翻译成代码，我们就可以完成之前的例子了。我们将从更简单的那个开始，即**星星三角形**。这里我们看到代码，作为之前泛化步骤的翻译（这些步骤作为注释放在代码中——每一行对应其正上方那一行算法中的指示）：

```c
// 打印 i 个星星
void printIStars(int i) {
  // 从 1 计数到 i（包含 i），计数变量称为 j
  for (int j = 1; j <= i; j++) {
    // 打印一个星星
    printf("*");
  }
}

// 打印 n 个星星组成的三角形
```

注意我们如何把 `printIStars` **抽象出来**。得到的函数**足够小、足够简单**，如果我们立刻就知道该怎么写，那么把它内联写出来也是合理的。然而，把它提取到自己的函数中并单独解决，**没有任何问题**。事实上，如果**不能立刻明显看出**该写什么来翻译它，那么把它抽象出去正是你应该做的。
