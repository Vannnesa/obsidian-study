# Step 5: Translation to Code
# 步骤 5：翻译成代码

现在你对你的算法有信心了，是时候把它**翻译成代码**了。这项任务可以用纸和笔完成（例如，在编程课的考试中你经常需要这样做），但大多数时候，你会想把代码实际输入到编辑器中，以便编译并运行你的程序。这里，我们将主要关注**从算法步骤到代码的翻译机制**。我们强烈建议你熟悉一款**程序员编辑器**（`Emacs` 或 `Vim`），并在编程时使用它。如果你需要入门，我们将在下一课中介绍 `Emacs`。

## Function declaration（函数声明）

我们应该从写下正在编写的函数的**声明**开始步骤 5，将其函数体（内部的代码）替换为步骤 3 中泛化后的算法，并写成**注释**。注释是程序中的一些行，它们在语法上表明**仅供人类阅读**（用于记录工作原理，帮助人们阅读和理解你的代码），而不是程序行为的实际组成部分。当你手工执行代码时，应该直接跳过注释，因为它们没有作用。在 C 中，有两种形式的注释：`//` 注释到行末，以及 `/*...*/` 把斜杠星号和星号斜杠之间的所有内容变成注释。

在写下函数声明时，我们可能需要做的一件事是弄清楚它的**参数类型**和**返回类型**。这些可能是给定的——在课堂编程题中，作业描述可能会告诉你；在专业环境中，它可能是项目团队成员之间约定的接口的一部分——然而，如果你不知道，你需要在继续之前弄清楚。

回到我们的矩形相交例子，我们知道正在编写的函数接受两个矩形，并返回一个矩形。之前，我们决定一个矩形可以表示为**四个数字**——这暗示了 `struct`（结构体）。然而，正如你之前所学，数字有多种不同类型——这些数字应该是 `int`（整数）？`float`（单精度浮点数）？`double`（双精度浮点数）？还是其他类型的数字？

关于我们需要哪种数字类型的问题，答案是“**视情况而定**”。你可能会惊讶地发现，“视情况而定”往往是许多编程相关问题的完全合理答案；然而，如果你给出这个答案，你应该描述**它取决于什么**，以及在不同情况下答案是什么。

对于我们的矩形例子，我们需要的类型取决于**我们用矩形做什么**。如果我们编写的是数学相关程序，其中矩形可以有分数坐标，那么实数类型 `float` 或 `double` 是合理的。在 `float` 和 `double` 之间选择，取决于我们需要在矩形上使用的**精度**和**范围**。如果我们做计算机图形学，并使用屏幕坐标（以离散像素为单位），那么 `int` 最合理，因为不能有分数像素。对于这个例子，我们将假设我们想使用 `float`。

做出这个决定后，我们就会通过声明函数并把算法写成注释，开始翻译成代码。
