# The Actual Compiler
# 实际编译器

**预处理器**的输出被存储在一个**临时文件**中，并传递给**实际编译器**。乍一看，编译过程的步骤之一竟然是“实际编译器”，这可能有点令人困惑。然而，我们经常用**同名步骤**来指代复杂过程。例如，如果你说“我要烤一个蛋糕”，即使只有一部分过程涉及实际烤蛋糕（在烤箱中烘烤蛋糕糊），我们仍然理解你会经历整个过程：找食谱、准备原料、搅拌面糊、烤蛋糕、让它冷却，以及给它抹糖霜。

编译器读取**预处理后的源代码**——其中所有指定文件都已被包含，所有宏定义都已被展开——并将其翻译成**汇编**（assembly）。汇编是**最低层次的人类可读代码**。在汇编中，每条语句对应**一条机器指令**。机器指令对应于非常简单的操作，例如把两个数字相加，或者把值移入或移出内存。虽然人类可以用汇编编程（有时有充分的理由），但这不是我们这里的重点——我们只想对编译过程有足够的理解，以便在编译程序时知道发生了什么。
