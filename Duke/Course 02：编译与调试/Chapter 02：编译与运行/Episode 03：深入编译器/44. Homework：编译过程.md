````quiz
编译器的哪一部分将目标文件、库和启动代码组合成可执行二进制文件？

[ ] assembler（汇编器）
[c] linker（链接器）
````

````quiz
## 问题 2
目标文件（object file）中包含什么？

[ ] 描述汇编代码需要哪些对象。
[ ] Java Object Descriptors（Java 对象描述符）。
[ ] 面向对象编程语言的源代码。
[c] 机器可执行指令。

目标文件包含所编译源文件的机器可执行指令，但它还不是一个完整程序，可能引用尚未定义的函数。
````

````quiz
## 问题 3
`gcc` 的 `-o` 选项做什么？

[ ] 按名称指定一个高级/不寻常的选项。
[ ] 指定 `gcc` 只生成目标文件。
[c] 指定 `gcc` 应产生的输出的名称。
[ ] 指定要使用的语言标准。

`-o` 用于指定输出文件名；`-c` 才是让 `gcc` 只生成目标文件。
````

````quiz
## 问题 4
如果你的代码需要引用整数能容纳的最大值，为什么应该使用 `INT_MAX`，而不是直接写 `214783647`？

[ ] 可移植性（Portability）
[ ] 减少错误风险
[ ] 可读性
[c] 以上所有

`INT_MAX` 定义在 `limits.h` 中，能根据平台提供正确的最大值，同时提高可读性并减少硬编码错误。
````

````quiz
## 问题 5
如果你有多个编译器错误，尝试修复后面的错误时可能遇到什么困难？

[ ] 修复编译器错误总体上很难。
[ ] 编译器只给出第一个错误的行号。
[ ] 编译器错误按从最简单到最复杂排序。
[c] 编译器可能会被较早的错误搞糊涂。

后面的错误可能只是编译器被前面的错误搞糊涂而产生的；通常应先修复第一个错误，再重新编译。
````
