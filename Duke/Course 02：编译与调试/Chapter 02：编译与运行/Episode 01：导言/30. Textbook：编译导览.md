# Compiling Overview
# 编译概述

一旦你写好了代码，就需要**编译**它才能运行。编译程序就是将程序员编写的人类可读代码（称为“**源代码**”，source code）翻译成**机器可执行格式**的行为。**编译器**（compiler）是为你执行这一过程的程序：它把你的源代码作为输入，并写出实际的可执行文件，然后你就可以运行它。

最简单的情况下，编译程序就是运行编译器，并给它一个命令行参数，指定包含程序源代码的 `.c` 文件。有许多不同的 C 编译器，但我们将使用 `gcc`，它代表“**GNU Compiler Collection**”（GNU 编译器集合）。如果你把程序写在名为 `myProgram.c` 的文件中，你可以执行命令 `gcc myProgram.c` 来编译代码。假设你的代码中没有错误，编译器会生成一个名为 `a.out` 的可执行程序，然后你可以通过输入命令 `./a.out` 来执行它。然而，如果你对前几章写过的任何 C 代码尝试这样做，你会遇到错误——我们需要在代码中再添加一点东西（我们很快就会看到），才能让它编译。

如果你不熟悉使用 UNIX/Linux 命令行界面，你可能想回顾上一模块中的 UNIX 阅读材料，以获取更多关于使用**命令行**和**命令行参数**的信息。我们将在课程 4 中更深入地讨论命令行参数。通常，你会用比一个源文件名更多的参数来调用编译器。我们将在介绍更多编译过程之后讨论这些选项。
