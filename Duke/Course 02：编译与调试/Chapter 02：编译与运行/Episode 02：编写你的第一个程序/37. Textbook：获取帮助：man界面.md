# Getting Help: man Pages
# 获取帮助：man 页面

当你编写自己的程序时，你会想学习一些提供**内置帮助**的命令。其中第一个，也是最通用的，是 `man` 命令（“manual”的缩写）。这个命令会显示你所请求内容的**手册页**（简称“**man 页面**”）——包括命令、库函数以及各种其他重要主题。例如，如果你输入 `man -S3 printf`，那么你的计算机会显示 C 库中 `printf` 函数的 man 页面。

像许多 UNIX 命令一样，`man` 在命令行上接受**参数**，以准确指定它应该做什么。对于 `man`，这些参数（通常）指定你想要它为你显示哪个（或哪些）页面。在上面的例子中，我们给 `man` 命令两个参数：`-S3` 和 `printf`。`-S3` 参数告诉 `man` 在手册的**第 3 节**中查找，这一节专门用于 C 库。

在深入探讨手册的选项和各节细节之前，我们先更仔细地看看手册显示的内容。上图显示了 `man -S3 printf` 的输出。这个页面实际上不仅有 `printf` 的信息，还有各种相关函数的信息，它们都列在页面顶部。`SYNOPSIS`（概要）部分列出了要使用的 `#include` 文件，以及函数的**原型**。屏幕底部是 `DESCRIPTION`（描述）部分的开始，它详细描述了函数的行为。这个描述超出了屏幕底部，但你可以用方向键上下滚动。你也可以使用 `d` 和 `u` 一次滚动一页。你还可以按 `q` 退出。这些是最重要和最有用的按键，但还有许多其他你可以使用的按键，你可以通过按 `h`（帮助）来了解它们。

如果你继续向下滚动 `printf` 的 man 页面，你会找到关于它的一切你想知道的内容（包括格式字符串的各种选项和特性、它在不同条件下返回什么值等）。在这个讨论中，我们对 `printf` 的细节不感兴趣，只关心 man 页面提供了这些细节。

手册还包括除 C 库之外其他主题的页面，例如命令。例如，`ls` 命令。如果你想了解这个命令的更多细节，可以执行 `man ls` 来阅读它。手册页描述了 `ls` 期望的命令行参数，以及它接受的各种选项的细节。

与 `printf` 不同，我们没有为 `ls` 指定手册的某一节。事实上，不明确指定节是常见情况——`man` 会按顺序浏览各节，试图找到我们请求的页面。如果手册较早的节中没有同名内容，那么你就不需要指定节。对于 `ls`，我们要找的页面在第 1 节——该节包含关于可执行程序和 shell 命令的信息。事实上，当你运行 `man ls` 时，你可以通过查看左上角看到它在第 1 节找到了页面，那里会显示 `LS(1)`。`(1)` 表示手册的第 1 节。

如果我们只输入 `man printf`，我们会得到第 1 节中 `printf` 命令的 man 页面（“printf(1)”）。这个页面对应于可执行命令 `printf`，它让你在 shell 中打印东西。例如，你可以在 shell 中输入 `printf "Hello %d\n" 42`，它会打印出 `Hello 42`。在编写脚本时，像这样打印信息可能很有用。由于 `man` 首先找到这个页面，如果我们想要 C 库函数 `printf`（例如，如果我们在编程，需要查找一个我们记不住的格式说明符），我们需要用 `-S3` 选项明确请求第 3 节，因为第 3 节有 C 库参考。

到目前为止，我们已经看到了手册的两节：第 1 节，用于可执行程序和 shell 命令；第 3 节，用于 C 库函数参考。如果没有这本书在手，我们怎么发现这些呢？另外，我们怎么了解手册的其他节呢？`man` 命令，像大多数其他命令一样，也有自己的手册页，所以我们可以直接阅读它。事实上，如果我们输入 `man man`，计算机会显示 `man` 命令的手册页。向下滚动一屏左右进入 `DESCRIPTION` 部分，会显示以下节表：

`man` 系统的新用户经常面临一个难题：如果你知道你需要什么，阅读 man 页面对于了解某事物的细节很好，但如果你不知道你在找什么，你怎么找到正确的页面呢？有两种主要方法可以找到这类信息。第一种是使用 `-k` 选项，它要求 `man` 进行**关键字搜索**。例如，假设你想找一个比较两个字符串的 C 函数。运行命令 `man -k compare` 会列出大约 56 个描述中包含单词 “compare” 的命令和 C 库函数。然后你可以浏览这个列表，找到看起来相关的内容，并阅读它们各自的页面以了解细节。

另一种查找方法是，如果你知道一些相关但不完全正确的东西，可以查看另一个页面末尾的 `SEE ALSO`（另见）部分。这个部分可以在每个 man 页面的末尾找到，它列出了作者认为与阅读她所写页面的读者相关的其他页面。
