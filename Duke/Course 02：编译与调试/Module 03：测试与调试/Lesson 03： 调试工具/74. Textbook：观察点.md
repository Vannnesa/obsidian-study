# Watchpoints
# 观察点

`gdb` 另一个极其有用的功能是**观察点**（watchpoint）——能够在某个特定表达式的值发生变化时让 `gdb` 停止。例如，我们可以写 `watch i`，这会导致每当 `i` 的值改变时 `gdb` 就停止。当 `gdb` 因观察点而停止时，它会打印该表达式的**旧值**和**新值**。

当你遇到与**指针**相关的问题，并且变量的值通过**别名**发生变化时，观察点可能是一个特别强大的工具。然而，有时我们设置观察点时使用的别名，可能在我们感兴趣的变化发生之前就**超出了作用域**。例如，我们可能想观察 `*p`，但 `p` 是一个局部变量，它的作用域在值改变之前就结束了。每当我们面临这样的问题时，我们可以打印 `p`，这会把指针放在一个 `gdb` 变量中（例如 `$6`），然后我们可以使用那个 `$` 变量（它永远不会超出作用域——它会一直存在，直到我们重启 `gdb`）来设置观察点：`watch *$6`。
