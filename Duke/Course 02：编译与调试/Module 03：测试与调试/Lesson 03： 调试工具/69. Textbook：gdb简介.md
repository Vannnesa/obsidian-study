# Intro to gdb
# gdb 简介

一旦你在代码中实现了算法，就必须测试它。测试常常会揭示你的代码存在错误（“bug”），然后你必须修复它们。**调试**（debugging）是精确识别代码哪里出错并修复它的过程。这个过程应该以**科学**的方式进行（而不是临时凑合地改来改去，并希望某个改动能奏效），而这个科学过程的一个关键组成部分就是**收集更多信息**。

调试过程中的一个关键工具是一个称为**调试器**（debugger）的软件。不过这个名字有点误导，因为这个程序实际上并不会替你调试代码，它只是帮助你收集关于代码中正在发生什么的信息。这里，我们将向你介绍一个特定的调试器，`gdb`，即 **GNU DeBugger**。强烈建议你熟练掌握调试器，因为它会大幅减少你花在尝试修复 bug 上的时间——这通常是新手最大的努力和挫败来源之一，因为他们往往既会犯很多错误，又难以修复这些错误。
