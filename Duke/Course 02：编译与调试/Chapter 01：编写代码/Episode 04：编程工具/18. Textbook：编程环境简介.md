# Introduction to the Programming Environment
# 编程环境简介

在本课程以及本专项课程（specialization）的其余课程中，你将在为本专项课程**定制**的环境中编写编程作业，我们将其称为**实践编程环境**（Practice Programming Environment，简称 **PPE**）。这将使你能够像专业人士一样在环境中编写代码，但你**不需要**在你用于本课程的机器上下载或安装任何东西。

每当课程中你的位置有作业要做时，你都会有一篇标题为 **“Assignment [assignment ID]”** 的阅读材料，编者注：由于这是本地Obsidian环境， 我不能确保每一个复刻都准确无误。

但是我的确复刻了一个由Bun+TypeScript驱动的grade评分系统！

如果你完全不懂什么是grade，别担心——我们将在下一课中带你了解如何使用实践编程环境，并向你介绍你将用来成为优秀程序员的最重要的技术工具！
