````quiz
## 问题 1
回想一下，如果两个矩形有重叠面积，则它们相交。一个新手可能会错误地用以下代码计算交集（注意顺序不应该有影响）：

```c
typedef struct rectangle_t {
    int x, y, width, height;
} rectangle;

rectangle intersection(rectangle r1, rectangle r2) {
    rectangle r;
    r.x = max(r1.x, r2.x);
    r.y = max(r1.y, r2.y);
    r.width = min(r1.width, r2.width);
    r.height = min(r1.height, r2.height);
}
```

给定以下矩形，以下哪一对矩形会让这段代码出错？提示：画图。

```c
r1 = {x = 0, y = 0, width =  2, height = 2}
r2 = {x = 1, y = 1, width = 2, height = 2}
r3 = {x = -2, y = -2, width = 6, height = 8}
r4 = {x = 1, y = 1, width = 1, height = 5}
```

[c] (r1, r2)
[ ] (r2, r3)
[ ] (r1, r3)
[ ] 以上全部都不正确

错误算法直接用 `min(width)` 和 `min(height)` 作为结果的宽高，而不是根据右边界和上边界重新计算。对于 `(r1, r2)`，正确交集宽高应为 1，但该算法会得到宽高 2。
````

````quiz
## 问题 2
如果你在一对不重叠的矩形 `(r1, r2)` 上运行你的算法，会返回什么？为什么这不是正确答案？

```c
r1 = {x = 0, y = 0, width = 2, height =  2}
r2 = {x = 3, y = 3, width = 2, height = 2}
```

对于实际问题，想想它们不能相交的其他方式——即，如果 `r2 = {x = 0, y = -10, width = 2, height = 2}` 会怎样？选择算法对 `r1` 和新定义的 `r2` 的交集返回什么。注意这不是这两个矩形的实际交集。

[c] {x = 0, y = 0, width = 2, height = 2}
[ ] {x = 2, y = 2, width = 1, height = 1}
[ ] {x = 0, y = 0, width = 1, height = 1}

对于新定义的 `r2`，`r1` 和 `r2` 在 y 方向完全不重叠（`r1` 的 y 范围是 [0,2]，`r2` 是 [-10,-8]）。错误算法会取 `max` 得到 y=0，取 `min` 宽高得到 2，因此返回了 `r1` 本身，而不是空交集。
````

````quiz
## 问题 3
以下哪一项描述的与 `r1 = {x = 2, y = 3, width = 3, height = 2}` 是同一个矩形？

后续：想想你的算法会如何处理负的 `width` 和 `height`。试着想出一种泛化修复的方法。

[ ] {x = 5, y = 3, width = -3, height = 2}
[ ] {x = 2, y = 5, width = 3, height = -2}
[ ] {x = 5, y = 5, width = -3, height = -2}
[c] 以上全部

`r1` 覆盖 x 从 2 到 5、y 从 3 到 5。允许负的宽高时，可以从不同的角出发描述同一个矩形：`{x=5, width=-3}` 表示 x 从 5 到 2；`{y=5, height=-2}` 表示 y 从 5 到 3。因此以上三种写法都表示同一个矩形。
````
