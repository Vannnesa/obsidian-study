# More about Macros
# 更多关于宏

标准头文件 `limits.h` 包含专门用于**可移植性**的常量。这些常量描述了当前平台上各种类型的**最大值和最小值**。例如，如果程序需要知道 `int` 的最大值和最小值，它可以分别使用 `INT_MAX` 和 `INT_MIN`。在 `int` 为 32 位的平台上，它们会被定义成这样：

```c
#define INT_MAX  2147483647
#define INT_MIN -2147483648
```

在 `int` 类型大小不同的平台上，它们会被定义成适合该平台上 `int` 大小的值。

宏也可以接受**参数**，然而，这些参数的行为与函数参数不同。回想一下，函数调用是在**程序运行时**求值的，参数的值会被复制到函数新创建的**栈帧**中。宏是由**预处理器**展开的（在程序编译时，甚至在程序开始运行之前），而参数只是**按文本展开**。事实上，宏参数**没有声明类型**，甚至不需要是合法的 C 表达式——只有展开后得到的文本需要是合法的（并且类型正确）。

我们可以（尽管我们很快会看到不应该）这样定义一个 `SQUARE` 宏：

```c
#define SQUARE(x) x * x
```

然后预处理器会把 `SQUARE(3)` 展开为 `3 * 3`，或者把 `SQUARE(45.9)` 展开为 `45.9 * 45.9`。注意，这里我们利用了宏参数没有类型这一点，在第一个例子中传入 `int`，在第二个例子中传入 `double`。然而，如果我们尝试 `SQUARE(z-y)` 会发生什么？如果这是一个函数，我们会把 `z-y` 求值为一个值，并把它复制到调用 `SQUARE` 的栈帧中。但这是宏展开，所以预处理器只处理**文本**。它通过把宏定义中的 `x` 替换为文本 `z-y` 来展开宏，得到 `z-y * z-y`。注意，这会计算 `z- (y*z) -y`，而不是 `z-y` 的平方。

我们可以这样定义来改进这个宏：

```c
#define SQUARE(x) ((x) * (x))
```

现在，`SQUARE(z-y)` 会展开为 `((z-y) * (z-y))`，无论参数和宏所在位置如何，都能给出正确结果。但如果宏参数有**副作用**，我们仍然可能遇到问题。例如，如果我们写 `SQUARE(f(i))`，那么函数 `f` 会被调用**两次**。如果 `f` 打印某些东西，它会打印两次，宏展开中对 `f` 的每次调用各一次。

`SQUARE` 宏有点刻意——我们最好在需要的地方直接写出乘法——但它突出了宏的**文本展开**的本质（和危险）。宏相当强大，可以用于一些相当复杂的事情，但在本专项课程中你编写的大多数内容并不需要它们。

# More about Header Files
# 更多关于头文件

头文件也可能包含**类型声明**。例如，`stdio.h` 包含一个 `FILE` 类型的类型声明，许多操作文件的函数都会使用它。这些函数也在 `stdio.h` 中有原型，我们将在学习访问文件和读取输入时讨论它们。

标准头文件中类型声明的另一个例子是 `stdint.h` 中的整数类型。如前所述，整数有不同的**大小**，而 `int` 的大小因平台而异。程序员通常不太关心 `int` 的大小，但有时使用**特定大小的整数**很重要。`stdint.h` 定义了诸如 `int32_t`（保证在任何平台上都是 32 位有符号整数）或 `uint64_t`（始终是 64 位无符号整数）这样的类型。

有了这些认识，我们可以重新审视之前的 Hello World 程序：

```c
#include <stdio.h>
#include <stdlib.h>
	
int main (void) {
  printf ("Hello World\n");
  return EXIT_SUCCESS;
}
```

预处理器会接收这段代码，并基本上把它转换成这样：

```c
int printf(const char *, ...);

int main (void) {
  printf ("Hello World\n");
  return 0;
}
```

实际上，预处理器的结果有几千行长，因为它包含了 `stdio.h` 和 `stdlib.h` 的全部内容，其中有许多其他函数原型和类型声明。然而，这些并不影响我们的代码（编译器会知道那些类型和函数存在，但既然我们不使用它们，它们就无关紧要）。我们要注意，`printf` 的原型包含一些我们还没见过的特性。你可以把 `const char *` 看作字面字符串的类型，而 `...` 意味着 `printf` 接受**可变数量的参数**——这是 C 的一个特性，除了用它来调用 `printf` 和类似函数之外，我们不会深入探讨。
