## 问题 1
什么工具对于构建包含许多源文件的大型程序很有用？

[ ] valgrind
[ ] emacs
[ ] gcc
[c] make

`make` 读取 `Makefile`，自动判断哪些文件需要重新编译和链接，从而高效构建大型程序。

````quiz
## 问题 3
对于以下 `Makefile`，以下哪一项描述了第 1 行的含义？

```make
myProgram: oneFile.o anotherFile.o
    gcc -o myProgram oneFile.o anotherFile.o
oneFile.o: oneFile.c oneHeader.h someHeader.h 
    gcc -std=gnu99 -pedantic -Wall -c oneFile.c
anotherFile.o: anotherFile.c anotherHeader.h someHeader.h 
    gcc -std=gnu99 -pedantic -Wall -c anotherFile.c
```

[r] 目标 `myProgram` 依赖于 `oneFile.o` 和 `anotherFile.o`
[ ] 从 `oneFile.o` 和 `anotherFile.o` 编译出 `myProgram`
[ ] 链接 `oneFile.o` 和 `anotherFile.o`

`Makefile` 中冒号左边是目标，右边是该目标所依赖的先决条件。
````

````quiz
## 问题 4
对于以下 `Makefile`，以下哪一项描述了第 4 行的含义？

```make
myProgram: oneFile.o anotherFile.o
    gcc -o myProgram oneFile.o anotherFile.o
oneFile.o: oneFile.c oneHeader.h someHeader.h 
    gcc -std=gnu99 -pedantic -Wall -c oneFile.c
anotherFile.o: anotherFile.c anotherHeader.h someHeader.h 
    gcc -std=gnu99 -pedantic -Wall -c anotherFile.c
```

[c] 将 `oneFile.c` 编译成目标文件
[ ] 目标 `oneFile.c` 依赖于头文件 `someHeader.h`
[ ] 将 `oneFile.c` 编译成可执行二进制文件

`gcc` 的 `-c` 选项表示只编译成目标文件（`.o`），不进行链接。
````
