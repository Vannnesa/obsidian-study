# Running Your Program
# 运行你的程序

既然你已经**编译**了程序，就可以运行它了。你可以像运行其他任何程序一样运行你的程序——在**命令提示符**下输入它的名称。然而，与你目前使用过的许多程序不同，你的程序所在的目录**不是 `PATH` 的一部分**——`PATH` 是一个**环境变量**，指定运行程序时要查找哪些目录。因此，你必须在名称中指定到哪个目录去找这个程序。由于程序就在当前目录中，你只需在程序名称前加上 `./`（例如 `./myProgram`）——告诉命令 shell 运行当前目录中的 `myProgram` 程序。如果你不熟悉命令 shell、目录、路径名或环境变量，可以回顾上一模块中的 UNIX 阅读材料。

你也可以在各种旨在帮助你**测试和调试**程序的工具内部运行你的程序。两个极其有用的工具是 `gdb`，即 **GNU 调试器**（我们稍后会讨论调试，特别是 `gdb`），以及 `valgrind`，它**模拟**计算机，但会跟踪更多关于程序正在做什么的信息，以报告那些否则可能**未被发现**的错误。
