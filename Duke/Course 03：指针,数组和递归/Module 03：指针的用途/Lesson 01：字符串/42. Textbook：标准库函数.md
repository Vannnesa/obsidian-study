# Standard Library Functions
# 标准库函数

我们已经见过几个 C 库中与字符串相关的函数。然而，还有更多可用的函数，因为字符串操作是编程中的常见任务。作为一条一般经验法则，如果你觉得“我敢打赌所有程序员都经常想对字符串做某件事”，那么 C 库很可能就有一个函数能对字符串做那件事——**连接**它们、在它们中**查找字符**、**求它们的长度**、在一个字符串中**查找另一个字符串**，等等。

你可以在它们的 **man 页面**中阅读所有这些函数。如果你不知道某个函数的名称，也可以查阅 `man string`，它会列出所有与字符串相关的函数及其各自的**函数原型**，帮助你找到你想要的东西。
