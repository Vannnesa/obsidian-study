# Converting Strings to ints
# 将字符串转换为整数

使用字符串时要记住的一件重要事情是：**字符串不能通过强制类型转换（无论是隐式还是显式）隐式转换为整数（或浮点类型）**。考虑以下代码片段：

```c
const char * str = "12345";
int x = str;
```

尝试编译这段代码会产生如下错误消息：

```text
initialization makes integer from pointer without a cast
```

这个错误出现的原因是，该赋值**不会**把字符串在文本上表示的数字转换为整数（也就是说，它不会得到 `x=12345`）。相反，它会取 `str` 的数值（`str` 是一个指针，因此它的数值是字符序列 `12345` 在内存中存储的**地址**），并把它赋给 `x`。这种行为完全遵循我们学过的赋值语句规则：将右侧求值为一个值（它是一个箭头，意味着它的数值是一个地址），然后把它写入左侧命名的盒子。

为了帮助更好地理解为什么简单赋值不行，上图给出了代码的“底层”视角：一个 `char *` 指向字符串 `"12345"`，以及一个值为 `12345` 的 `int`。图的左侧展示了我们通常使用的概念表示。图的右侧展示了程序的相同状态，但带有地址以及那些地址中包含的数值。变量 `str`（其字节用红色标出）是一个指针，在这个特定系统上是 8 字节。它的数值是字符串字面量 `"12345"` 的字节在内存中的地址，即 `0x100000f40`。内存位置 `0x100000f40–0x100000f45` 的内容是该字符串的字符——依次是字符 `'1'`（`0x31`）、`'2'`（`0x32`）、`'3'`（`0x33`）、`'4'`（`0x34`）、`'5'`（`0x35`）和 `'\0'`（`0x00`）的数值。变量 `x` 是一个 `int`，占 4 字节，保存值 `0x00003039`，即十进制的 `12345`。

如果我们说服编译器允许我们赋值 `x = str`，我们会把 `str` 的值（即 `0x100000f40`）复制到 `x` 中。当然，由于 `x` 无法容纳整个值（记住，在这个特定系统上，指针是 8 字节，而 `int` 是 4 字节），该值会被**截断**。`x` 最终会被赋值为 `0x0000f40`（`0x100000f40` 的最低四个字节），即十进制的 `3904`——仍然不是我们想要的。

另一个错误（至少对这个任务来说）的方法是写 `x = *str`，解引用 `str` 来获取箭头末端的值，而不是指针本身。这里，我们会从字符串中读出一个字符（`*str` 求值为 `'1'`，即 `0x31`）。然后我们会把这个值（`0x31`）赋给 `x`。现在，我们会得到 `x` 为 `0x31`（即十进制的 `49`）——也不是我们想要的！

虽然前面的例子由于使用了字面量字符串可能显得有点刻意（为什么不直接写 `int x = 12345;` 呢），但考虑一个更有用的例子：

```c
printf("Please enter a number:");
char * str = readAStringFromTheUser(); // 我们稍后会学习如何做
int x = str; // 他们会输入一个字符串。
             // 我们想把它存储为 int……
```

这个例子不仅说明了为什么我们可能想执行这类操作，还引导我们理解这类任务中的一个复杂之处。如果用户输入 `"xyz"` 怎么办？我们如何把它转换为数字？就此而言，如果我们的代码改为读取（注意“用十六进制”）：

```c
printf("Please enter a number in hexadecimal:");
char * str = readAStringFromTheUser(); // 我们稍后会学习如何做
int x = str; // 他们会输入一个字符串。
             // 我们想把它存储为 int……
```

现在，如果用户输入字符序列 `12345`，他们指的不是数字 `12,345`（一万二千三百四十五），因为我们告诉过他们会把它解释为十六进制。相反，它是十进制的 `74,565`（你可以自己练习这个转换）。

如果我们想自己手工执行这种转换，我们需要遍历字符串中的字符并进行数学运算。然而，由于这类转换是常见任务，C 库中有为我们执行它的函数。`atoi` 函数是其中最简单的——它通过把字符序列解释为十进制数字来把字符串转换为整数。如果开头没有有效数字，它返回 `0`。稍微复杂一点的函数是 `strtol`，它让你指定**基数**（十进制、十六进制等），还可以传入一个 `char *` 的地址，它会把该指针填充为指向数字后面第一个字符的指针。也就是说，如果你给它字符串 `123xyz`，它会把这个指针设置为指向 `'x'`（如果你不需要这个额外信息，也可以传入 `NULL`，在这种情况下它会跳过这部分）。这个额外参数允许你做错误检查，和/或弄清楚数字后面是什么（如果它是你需要处理的更大输入的一部分，例如逗号分隔的数字列表）。

这个概念一开始可能有点令人困惑，因为你习惯于看到数字的文本表示（例如，它在纸上写出的十进制形式，并把它当作数字本身）。理解这个概念的最好方式是自己编写这些从字符串到整数的转换函数（一般来说，**边做边学**是最好的）。如果你想在这个领域获得一些额外练习，我们建议你尝试以下可选练习：

- 编写函数 `int myatoi(const char * str)`，其行为像 `atoi` 函数，只是由你自己编写（不使用 `atoi` 或 `strtol`）。
- 编写函数 `int myatoiHex(const char * str)`，其行为像 `atoi` 函数，只是 (a) 它把字符串解释为**十六进制**（基 16）数字而不是十进制，并且 (b) 由你自己编写（不使用 `atoi` 或 `strtol`）。
- 编写函数 `long mystrtol(const char * str, char ** endptr, int base)`，其行为像 `strtol`，只是由你自己编写（不使用 `atoi` 或 `strtol`）。

以下是一些帮助你解决这些问题的提示：

- 记住**一切都是数字**，包括字符。这意味着你可以做一些事情，比如取一个字符 `c` 并把它与其他字符比较（例如 `c >= '0'`），用一个字符减去另一个字符（`c - '0'`），或任何你可能想做的其他数学运算。注意，数字 `0--9` 都有连续的数值，所以 `'7' - '0'` 是 `7`。
- 记住在十进制数字中，每一位都是前一位的 10 倍大：`12` 是 `(10 * 1) + 2`。`123` 是 `100 * 1 + 10 * 2 + 3`。把它想成 `(1 * 10 + 2) * 10 + 3` 可能有帮助。同样，`1234` 是 `((1 * 10 + 2) * 10 + 3) * 10 + 4`。
- 对于基 16，类似的原则适用，但每一位是前一位的 16 倍大：`0x1fc` 是 `(1 * 16 + 15) * 16 + 12`。
