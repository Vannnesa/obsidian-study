# Introduction
# 引言

之前，我们学习了**数组**（array），它让我们能够存储同一类型元素的序列，并通过索引访问数组中的特定元素。我们可以用**多维数组**（multidimensional arrays）扩展这个概念。例如，我们可能想把一个数学**矩阵**（matrix，它在概念上是矩形而非线性的）表示为一个二维数字数组，或者把一幅图像表示为一个二维颜色数组。如果我们想要一个字符串数组，实际上最终会得到一个二维字符数组，因为字符串本身就是字符数组。

一如既往，决定如何表示数据是算法设计过程**步骤 2** 的一部分，在这一步中你要弄清楚自己在**步骤 1** 中究竟做了什么。你已经学到，表示为同一类型元素序列的数据，自然适合用数组表示。当你的数据自然地以更高维度的组织方式出现时，这个概念就扩展到多维数组。你可以创建任意维度的多维数组，因此你可以表示任意维度的数据。例如，如果你的程序处理的数据按一年中的**天**组织，每一天内又按**小时**组织，每一小时内又按建筑物内的**房间号**组织，那么自然的表示就是一个三维数组：`365 x 24 x (房间数)`。
