# Incompatibility
# 不兼容性

多维数组的一个方面常常让新手 C 程序员困惑：表示多维数据的这两种方式**彼此不兼容**——它们是不同的类型，不能从一种隐式转换为另一种。事实上，如果你尝试通过强制类型转换（cast）从一种显式转换为另一种，你会得到从无意义答案到程序崩溃的各种结果。这个常见问题强调了**了解你所声明类型的确切含义，并完全理解你所写每一行代码语义**的重要性。

当程序员在不理解自己所做事情的含义的情况下，天真地插入一个强制类型转换来“修复”编译器错误时，问题就会出现——程序崩溃；还可能产生更糟糕的后果。回想一下，一个给出错误答案（且没有任何出错迹象）的程序，往往比一个崩溃的程序**糟糕得多**。我们可能会反而读取或写入我们不打算读写的值，并产生**虚假的结果**。
