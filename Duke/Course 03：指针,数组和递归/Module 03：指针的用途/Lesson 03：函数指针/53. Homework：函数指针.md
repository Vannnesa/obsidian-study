````quiz
## 问题 1
什么是函数指针（function pointer）？

[c] 指向函数中第一条指令的指针
[ ] 一个返回值为指针的函数
[ ] 一个参数为指针的函数
[ ] 指向函数中最后一条指令的指针

函数名本身是指向该函数第一条指令的指针，函数指针通常用于存储或传递函数的地址。
````

````quiz
## 问题 2
函数指针最有用的应用是什么？

[ ] 作为 `int *` 类型的替代
[ ] 作为命令行参数
[c] 作为函数的参数
[ ] 作为函数的返回值

把函数指针作为参数传入，可以让一个函数接收“要执行的操作”，从而实现通用函数（如 `qsort` 的比较函数）。
````

````quiz
## 问题 3
C 库函数 `qsort` 如何利用函数指针？

[ ] 它返回一个函数指针，指出使用了哪个排序函数。
[c] 它接受一个函数指针作为参数，指定如何比较两个元素。
[ ] 把指向 `qsort` 的函数指针传递给比较函数。
[ ] 它用 `switch/case` 语句选择使用哪个比较函数。

`qsort` 的第四个参数就是比较函数的指针，由调用者提供，用来决定元素的排序顺序。
````
