# Use Memory Checker Tools
# 使用内存检查工具

既然你开始使用**指针**，使用**内存检查工具**就至关重要，例如 `valgrind` 和/或编译器选项 `-fsanitize=address`。这些工具将帮助你发现**错误行为**，并使修复程序更容易。请在**整个测试过程**中都使用它们。

有关 `valgrind` 及其 `memcheck` 工具的更多信息，请参阅本专项课程课程 2 中的介绍：  
https://www.coursera.org/learn/writing-running-fixing-code/supplement/Zq2y5/valgrind
