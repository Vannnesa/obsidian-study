````quiz
## 问题 1
我们在概念上把指针表示为箭头，但**一切都是数字**。箭头是什么数字？

[ ] 箭头所指盒子中数字的副本
[c] 内存中的一个地址
[ ] 一个表示箭头长度的 `double`
[ ] 一个表示有多少个箭头的 `int`

指针在硬件中存储的是它所指向变量的**内存地址**，因此箭头对应的数字就是地址。
````

````quiz
## 问题 2
局部变量存储在内存的哪个区域？

[ ] Code（代码区）
[c] Stack（栈）
[ ] Static data（静态数据区）
[ ] Heap（堆）

局部变量在函数被调用时存放在**栈帧**中，函数返回后随之释放。
````

````quiz
## 问题 3
值为 `NULL` 的指针数值为 0。地址 0 处放了什么？

[ ] 来自栈的溢出
[ ] 一个全零字节
[c] 什么都没有
[ ] 程序指令的开始

程序不会把任何有效部分放在地址 0，因此地址 0 处**没有任何东西**；解引用 `NULL` 会导致段错误。
````
