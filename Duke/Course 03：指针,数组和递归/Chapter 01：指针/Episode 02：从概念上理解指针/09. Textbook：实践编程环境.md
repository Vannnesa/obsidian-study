# The Practice Programming Environment
# 实践编程环境

## Learners Continuing from Course 2
## 从课程 2 继续的学习者

如果你和我们一起学习了课程 2：“用 C 编写、运行和修复代码”，你应该已经熟悉**实践编程环境**（Practice Programming Environment，PPE），并且应该已经有下一个作业可用。如果你还没有，你应该从课程 2 的 PPE 中下载你的**主文件夹**。

当你为下一个作业启动 PPE 时，使用终端右下角的按钮上传你主文件夹的 **ZIP 压缩包**。点击 “Browse” 或 “Choose File” 按钮选择 `home-archive.zip` 文件，然后点击黄色的 **Upload Home Archive** 按钮，把你的主文件夹发送到本课程的 PPE。上传完成后，你应该把课程 2 的所有文件添加到 git：

```bash
$ cd learn2prog
$ git add .
$ git commit -m "Initial commit for Course 3"
$ git push
```

## Learners Upgrading from a Previous Version of Course 3
## 从课程 3 旧版本升级的学习者

如果你在这个版本发布时正在学习课程 3，你需要让 PPE 赶上你的进度。你应该在升级到新版本之前下载了你的主目录。如果你没有，你需要按照下一节中针对没有压缩包可上传的学习者的说明操作。

首先，你应该按照上一节的步骤上传你的主压缩包，并把所有文件添加到 Git。

接下来，你需要**重新评分**你的作业。这从 `learn2prog` 文件夹中最容易完成。为你已完成的每个作业运行 `grade` 命令：

```bash
$ cd ~/learn2prog
$ grade 11_read_ptr1
$ grade 12_read_ptr2
$ grade 13_read_arr1
... （对每个已完成的作业重复 grade 命令）
```

## Learners Who Did Not Complete Course 2
## 没有完成课程 2 的学习者

如果你没有和我们一起学习课程 2，那么你可能不熟悉 PPE。如果你想先学习课程 2，那是个好主意，你可以在这里找到它：

https://www.coursera.org/learn/writing-running-fixing-code/

如果你不想那样做，当你进入 PPE 时，可以运行：

```bash
$ cd learn2prog
$ fast-forward 11_read_ptr1
$ git pull
```

来让下一个作业对你可用，跳过所有课程 2 的作业（如果你以后学习课程 2，你会在学习课程 2 的过程中逐个获得它们）。然后你可以：

```bash
$ cd 11_read_ptr1
```

并在 `Emacs` 中打开 `README` 来获取作业说明。

注意， 这些在Obsidian暂时不可用。请恭候后期说明。
