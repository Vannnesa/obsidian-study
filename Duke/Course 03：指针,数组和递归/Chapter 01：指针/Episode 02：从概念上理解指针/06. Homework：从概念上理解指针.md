## 问题 1
以下代码片段执行后，`x` 的值是多少？

```c
int x = 3;
int * p = &x;
*p = 4;
```

答案:
````spoiler
**4**
````

````quiz
## 问题 2
以下这行代码的合法性/非法性如何描述？

```c
int * b = 42;
```

[ ] 非法：我们必须把指针命名为 `p` 或 `q`。
[c] 非法：`42` 的类型与 `b` 的类型不同。
[ ] 非法：你不能在同一行声明并初始化指针。
[ ] 合法。

指针只能被初始化为地址（例如通过 `&x` 取得），不能直接把整数 `42` 赋给 `int *` 类型的变量。
````

````quiz
[ ] 直接操作指针底层的二进制表示
````
