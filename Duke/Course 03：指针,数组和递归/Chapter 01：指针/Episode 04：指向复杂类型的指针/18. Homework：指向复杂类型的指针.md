````quiz
## 问题 1
假设 `a` 是一个指向带有字段 `x` 的结构体的指针，以下哪一项与 `(*a).x` 具有相同的语义（含义）？

[ ] `*(a.x)`
[ ] `*a.x`
[c] `a->x`
[ ] `x->a`

`->` 运算符是“解引用指向结构体的指针并选择字段”的简写，因此 `a->x` 与 `(*a).x` 等价。
````

````quiz
## 问题 2
如果我们写 `&e`，那么 `e` 必须是……

[c] 一个 `lvalue`
[ ] 一个指针
[ ] 一个结构体
[ ] 一个表达式

`&` 是取地址运算符，只能应用于 `lvalue`（即命名一个内存“盒子”的表达式）。
````

````quiz
## 问题 3
对于以下代码：

```c
const int * p = &x;
```

以下哪一项会导致编译器错误？

[ ] `p = NULL;`
[c] `*p = 5;`
[ ] `p = &y;`
[ ] `x = 5;`

`p` 是指向 `const int` 的指针，因此不能通过 `p` 修改它所指向的值；`*p = 5;` 会试图修改只读位置，导致编译错误。其他选项修改的是指针本身或非 `const` 的 `x`，都是合法的。
````
