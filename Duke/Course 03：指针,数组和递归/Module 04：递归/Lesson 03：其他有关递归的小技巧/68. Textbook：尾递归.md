# Tail Recursion
# 尾递归

我们目前见过的递归函数使用**头递归**（head recursion）——它们在**进行递归调用之后**执行计算。在 `factorial` 例子中，递归调用 `factorial` 之后，返回的结果会先乘以 `n`，然后才返回该答案。还有另一种形式的递归，称为**尾递归**（tail recursion）。在尾递归中，**递归调用是函数返回前做的最后一件事**。也就是说，对于尾递归函数 `f`，唯一的递归调用会出现在 `return f(...);` 这种上下文中——一旦对 `f` 的递归调用返回，这个函数就立即返回它的结果，不再做任何进一步计算。

这个想法的一个推广（与递归本身分开）是**尾调用**（tail call）——如果调用者在被调用函数返回后立即返回，不再做进一步计算，那么这个函数调用就是尾调用。换种说法：如果函数 `f` 调用函数 `g`，那么对 `g` 的调用是尾调用，当且仅当 `g` 返回后 `f` 唯一做的事就是立即返回 `g` 的返回值（或者如果 `f` 的返回类型是 `void`，就直接返回）。这两个概念联系在一起：**一个递归函数是尾递归的，当且仅当它的递归调用是尾调用**。为了理解这个定义，让我们看一个 `factorial` 函数的尾递归实现：

```c
int factorial_helper (int n, int ans) { 
  // 基准情况
  if (n <= 0) {
    return ans;
  }
  // 递归调用是尾调用
  // 递归调用返回后，直接返回它的答案
  return factorial_helper (n - 1, ans * n); 
}
```

这里我们有一个**尾递归辅助函数**（helper function）——我们的主函数调用它来完成大部分工作。辅助函数在尾递归中相当常见，但也可能出现在其他上下文中。辅助函数接受一个额外参数，用于保存它在递归过程中构建起来的答案。主函数只是调用这个函数，传入 `n` 和 `1`。注意递归调用是**尾调用**。那次调用返回后发生的一切，就是立即返回它的结果。注意，尾递归版本的 `factorial` 并不比原来的递归版本做更少的工作。在原来的递归版本中，一个数的阶乘是通过每次递归调用之后进行的一系列乘法得到的。在尾递归版本中，这个乘法发生在递归调用**之前**。运行中的乘积存储在尾递归函数的第二个参数中。
