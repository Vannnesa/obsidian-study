# Swap Revisited
# 重新审视交换

既然我们已经了解了**指针**，我们就可以编写能够访问和操作另一个函数中变量的函数——我们可以传递指向我们希望被调用函数操作的位置的指针。现在我们有了编写正确版本 `swap` 的工具。关键在于把原始变量 `a` 和 `b` 的指针传递给 `swap` 函数，如下所示：

```c
void swap(int *x, int *y) {
  int temp = *x;
  *x = *y;
  *y = temp;
}
	
int main(void) {
  int a = 3;
  int b = 4;
```

因为变量 `x` 和 `y` 持有指向原始变量 `a` 和 `b` 的箭头，所以该函数可以交换**调用者函数**的变量，而不仅仅是它自己的**局部副本**。现在，参数告诉我们的是要操作的数据的**位置**，而不是要操作的**值**。然而，它可以通过**解引用**这些指针来操作那些位置上的值。
