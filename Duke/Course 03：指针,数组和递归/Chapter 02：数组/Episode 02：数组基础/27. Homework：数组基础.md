````quiz
## 问题 1
考虑以下数组声明和初始化：

```c
int arr[3] = {0, 1, 2};
```

语句“`arr` 是一个 `lvalue`”是真还是假？

[ ] True
[c] False

数组名 `arr` 不是 `lvalue`，它只是一个指向数组第一个元素的指针，不能改变它指向的位置。
````

````quiz
## 问题 2
以下哪两项与 `arr[i]` 在语义上相同？

[ ] `*arr + i`
[ ] `arr + *i`
[c] `*(arr + i)`
[c] `i[arr]`

`arr[i]` 在底层等价于 `*(arr + i)`。由于加法可交换，`i[arr]` 也等价于 `*(i + arr)`，即 `*(arr + i)`。
````

````quiz
## 问题 3
以下哪一项最好地描述了当你越界索引数组时会发生什么？

[ ] 编译器会给出错误。
[ ] 程序会发生段错误。
[ ] 程序会访问那个盒子中的任意值。
[c] 行为是未定义的。

越界访问数组是**未定义行为**，编译器通常无法检测，程序可能崩溃、可能读到垃圾值，也可能看似正常，但都不保证。
````
