# Passing Arrays as Parameters
# 将数组作为参数传递

一般来说，当我们想传递一个数组作为参数时，我们会想传递一个指向该数组的**指针**，以及一个指定数组中有多少个元素的**整数**，像这样：

```c
int myFunction(int * myArray, int size) {
  // 任意代码...
}
```

在 C 中，除了显式传递该信息之外，**没有办法获取数组的大小**，而且我们通常想编写在所能操作的数组大小上**通用**的函数（即，我们不想把函数硬编码为只能处理特定大小的数组）。如果我们愿意，可以创建一个**结构体**，把数组和它的大小放在一起，作为一份数据——然后传递那个结构体。

当我们传递一个实际指向数组的指针时，我们可以像数组一样索引它（因为它就是数组——记住，数组变量的名称只是一个指针），并对其进行**指针算术**。只要得到的指针仍然在数组边界内，这样的指针算术就是**良定义**的，因为我们保证数组元素在内存中是**顺序存放**的。

我们也可以用方括号语法把数组作为参数传递：

```c
int myFunction(int myArray[], int size) {
  // 任意代码...
}
```

这个定义在功能上等价于我们之前看到的指针语法版本。有些人更喜欢它，因为它更明确地表明 `myArray` 意图是一个数组。我们也可以在方括号中写一个大小，然而，编译器不会尝试检查那个大小是否实际正确，因此很容易在那里写错东西（或者随着你修改代码而变得不正确），并可能让读者困惑。

当你调用一个接受数组的函数时，你可以传递任何求值为指向元素序列的指针的表达式。通常，这个表达式就是数组的名称（它是指向第一个元素的指针）。然而，我们可以对数组执行**指针算术**（以得到指向数组中间某个元素的指针——这是一个有效但更短的数组），或者我们可能从其他变量中获取指针——它可能是结构体中的一个字段，甚至是另一个数组中的一个元素。
