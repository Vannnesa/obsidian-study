# 阅读递归代码

像我们通常做的那样，我们先学习阅读，再学习编写。然而，与我们遇到的大多数东西不同，实际上并没有任何新的语义要学——我们只是遵循已经学过的相同规则。不过，我们仍然会提醒你执行函数调用的规则，并强调它们对于**递归函数**完全一样。

我们将以 `factorial` 函数为例开始。回想一下，在数学中，一个数的**阶乘**（数学记号写为 `n!`）是：

![[Pasted image 20260921143615.png]]

你可能注意到一件事：这个函数的数学定义是**递归的**——`n>0` 的一般情况是用更小数的阶乘 `((n-1)!)` 来表达的。由于问题本身是递归的，**递归算法是自然的选择**。我们稍后会看到如何设计和实现算法，但现在，我们只需从以下计算阶乘的代码开始：

```c
int factorial(int n) {
  if (n <= 0) {
    return 1;
  }
  return n * factorial(n-1);
}
```

如果你花一点时间检查这段代码，你会看到其中所有内容都是我们见过的。第 1 行告诉我们这个函数叫 `factorial`，接受一个 `int`（`n`），返回一个 `int`。第 2 行有一个 `if` 语句，带有一个条件表达式（`n <= 0`），现在应该非常熟悉了。第 3 行包含 `if` 语句的 “then” 子句，只是返回 `1`。第 5 行返回一个表达式，它是 `n` 乘以用参数 `n-1` 调用 `factorial` 函数的结果。

每当我们的执行箭头到达第 5 行，我们都**完全按照之前学过的方式**做事。我们把 `n`（从它的盒子中读出）乘以 `factorial(n-1)` 返回的值。为了计算 `factorial(n-1)`——它本身是一个函数调用——我们需要为 `factorial` **画一个栈帧**（为参数 `n` 准备一个盒子，计算 `n-1` 并把它复制到参数盒子中，记下返回哪里，并把执行箭头移动到 `factorial` 函数的开头。
