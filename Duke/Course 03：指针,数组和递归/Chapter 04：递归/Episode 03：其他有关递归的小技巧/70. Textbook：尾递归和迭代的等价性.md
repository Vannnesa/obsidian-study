# Equivalence of Tail Recursion and Iteration
# 尾递归与迭代的等价性

既然你已经看到尾递归函数如何执行，花点时间用**迭代**（循环）写一个 `factorial`，并对 `n=3` 手工执行它。你注意到迭代执行和尾递归执行之间有什么相似之处吗？不同之处呢？在继续之前，花一分钟尝试一下（可能在你完成 `factorial` 的迭代实现/执行后，再重新看一遍视频）。

具体来说，让我们考虑以下 `factorial` 函数的迭代实现：

```c
int factorial (int n) {
  int ans = 1;
  while (n > 0) {
    ans = ans * n;
    n--;
  }
  return ans;
}
```

手工执行这个迭代实现和你刚刚看到的尾递归实现，会发现它们的行为几乎相同。有了上一个视频末尾看到的**尾递归消除**优化，尾递归实现甚至不会创建任何新栈帧（与迭代实现相同）——它只是**复用现有的栈帧**。

我们强调这种相似性，是为了帮助你理解一个重要观念：**尾递归和迭代是等价的**。任何我们能用迭代编写的算法，都可以平凡地转换为尾递归，反之亦然。聪明的编译器会把尾递归代码和迭代代码编译成**完全相同的指令**。

一般来说，如果我们有一个像这样的循环（注意这不是真正的 C，而是**伪代码**——它像代码，但不完全是代码：`expr` 是表达式的占位符，`someCode` 是任意代码的占位符，等等）：

```text
t1 var1 = expr1;  // t1..tN 是类型（如 int）
t2 var2 = expr2;
…
tN varN = exprN;
	
while (condition) {  // 任意条件表达式
  someCode;          // 我们可能在这里做一些其他代码
                     // 例如打印一些东西
  var1 = update1;
  var2 = update2;
```

我们可以把它转换成这样的尾递归：

```text
appropriateType helper(t1 var1, t2 var2, … tN varN) {
  if (!condition) {
    return ansExpr;
  }
  someCode;
  return helper(update1, update2, … updateN);
}
```

反过来也成立——我们可以通过反向操作把尾递归转换为 `while` 循环。

尾递归与迭代的等价性对**函数式编程语言**尤其重要。在纯函数式语言中，一旦创建了一个值，你就不能真正修改它（至少从语言的角度看是这样：编译器可以自由地复用同一个“盒子”，如果它能断定你永远不会再使用它）。因此，那里没有循环（循环通常需要修改变量来改变条件），而只有递归函数。你通常会用循环写的东西，在函数式语言中只需写成尾递归函数。

**函数式编程**是一件美好的事情，我们强烈建议任何认真的、有抱负的程序员至少熟练掌握一种函数式语言。作者之一特别喜欢 **SML**，并强烈推荐它。即使你的主要编程工作使用其他语言（如 C、Java、C++ 或 Python），拥有函数式语言的经验也能帮助你以不同方式思考问题，并让你成为一个全面更好的程序员。当然，你也可能最终把函数式语言用于你的主要工作。
