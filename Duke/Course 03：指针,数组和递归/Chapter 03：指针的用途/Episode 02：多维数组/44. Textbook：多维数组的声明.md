# 声明

在 C 中，**多维数组就是数组的数组**——二维数组是其元素为一维数组的数组；三维数组是其元素为二维数组的数组；依此类推。相应地，我们用多组方括号来声明它们，每组方括号表示对应维度的大小。例如，我们可以像这样声明一个 4 元素乘 3 元素的二维 `double` 数组（例如，用作一个 4x3 的数学矩阵）：

```c
double myMatrix[4][3];
```

![[Pasted image 20260921141300.png]]

以这种方式声明 `myMatrix` 会得到一个包含四个元素的数组。`myMatrix` 的每个元素都是一个包含 3 个 `double` 的数组。相应地，`myMatrix` 占用 `(4 * 3 * sizeof(double))` 字节内存，其中 `myMatrix[0]` 的三个元素连续出现，接着是 `myMatrix[1]` 的三个元素，依此类推。上图右侧描绘了这种布局，左侧则描绘了矩阵的概念（即矩形）布局。在图的左右两侧，`myMatrix` 的第 0 个元素（“行”）用绿色标出，第 1 个用粉色，第 2 个用蓝色，第 3 个用橙色，这样你可以很容易地看到数据是如何布局的。具体的地址并不重要（它们只是示例——会因程序而异），但旨在展示所有元素在内存中是如何**连续存放**的。
