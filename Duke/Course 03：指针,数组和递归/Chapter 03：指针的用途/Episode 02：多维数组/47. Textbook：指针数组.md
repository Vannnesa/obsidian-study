# Array of Pointers
# 指针数组

我们也可以用**显式持有指向其他数组的指针**的数组来表示多维数据。例如，我们可能写：

```c
double row0[3];
double row1[3];
double row2[3];
double row3[3];
double * myMatrix[4] = {row0, row1, row2, row3};
```

![[Pasted image 20260921141542.png]]

在上图中，我们仍然有一个 4x3 矩阵，然而，这个矩阵在内存中的表示方式相当不同。这里，`myMatrix` 是一个包含 4 个指针的数组，这些指针显式地指向作为矩阵各行的数组。在图的左侧，描绘了这个数据结构的概念表示：`myMatrix` 是一个包含 4 个指针的数组，每个指针指向 `row0`–`row3` 中的一个数组。图的右侧描绘了这个数据结构在内存中的布局。这里，每个行数组在内存中**可能并不彼此相邻**（它们可能相邻，但不是必须的）。`myMatrix` 的四个条目现在持有指向四个行数组的指针（即它们的地址）。

对于这两种表示，数组元素的访问方式类似。对于任一种表示，`myMatrix[2]` 都求值为一个指向矩阵第二行数组的指针。同样，`myMatrix[2][1]` 求值为矩阵第二行第一列的那个 `double`。

然而，也有一些**显著差异**。首先，在这种**指针数组**表示中，指向各行的指针是**显式存储在内存中**的。相应地，求值 `myMatrix[i]` 实际上涉及从内存中读取一个值，而不仅仅是计算一个偏移量。这种差异有性能影响，我们这里不深入讨论，因为我们还没有准备好讨论性能（这样的讨论需要对硬件有详细了解）。

显式存储指向矩阵各行的指针，使我们能够用这种表示做一些用第一种表示做不到的事情。首先，我们**不再受限于每一行与其他行大小相同**。其次，在指针数组表示中，`myMatrix[i]` 是一个 `lvalue`（回想一下，如果我们只是声明一个多维数组，它就不是 `lvalue`）。相应地，如果我们愿意，可以改变指针指向的位置。第三，我们可以让**两行指向完全相同的数组**（互为别名）。虽然这些能力对于数学矩阵来说可能不太有用，但它们对各种其他具有多维数据的任务可能非常有用。这种指针数组表示在我们学习**动态分配**时也会证明相当有用。
