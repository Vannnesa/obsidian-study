# Initializing
# 初始化

我们可以在声明多维数组的同一行中，用**大括号初始化器**（braced initializer）来初始化它，就像一维数组一样。对于多维数组，我们应该记住数组的每个元素本身就是一个数组，并为它写一个大括号初始化器：

```c
double myMatrix[4][3] = { {1.0, 2.5, 3.2},    // myMatrix[0] 的元素
                          {7.9, 1.2, 9.9},    // myMatrix[1] 的元素
                          {8.8, 3.4, 0.0},    // myMatrix[2] 的元素
                          {4.5, 9.2, 1.6} };  // myMatrix[3] 的元素
```

当我们以这种方式初始化数组时，可以**省略第一维**，因为编译器可以从初始化器中确定有多少个元素：

```c
// 同样合法：从 [] 中去掉了 4
double myMatrix[][3] = { {1.0, 2.5, 3.2},    // myMatrix[0] 的元素
                         {7.9, 1.2, 9.9},    // myMatrix[1] 的元素
                         {8.8, 3.4, 0.0},    // myMatrix[2] 的元素
                         {4.5, 9.2, 1.6} };  // myMatrix[3] 的元素
```

即使你提供了完整的初始化器，也**不能省略第二维的大小说明**。在声明函数参数时，你也可以省略第一维的大小，但不能省略任何其他维度的大小。

多维数组不限于二维。对于更多维度，你可以写额外的 `[ ]` 来指定每个额外维度的大小：

```c
int x[4][2][7];  // x 是一个 3D 数组，有 4 个元素，每个元素是
                 // 一个包含 2 个元素的数组
                 //（其元素是 7 个 int 的数组）
char s[88][99][122][44]; // s 是一个 4D char 数组：88 x 99 x 122 x 44。
```

所有这些相同的规则都适用于更多维度的数组。如果我们写 `x[1]`，我们得到一个指向二维数组的指针，该数组是 `x` 的第 1 个元素。如果我们写 `x[1][1]`，我们得到一个指向一维 `int` 数组的指针，该数组是那个数组的第 1 个元素；如果我们写 `x[1][1][4]`，我们得到 `int`，即那个数组的第 4 个元素。如果我们愿意，也可以用大括号初始化器初始化这些数组（尽管为具有许多维度的大数组编写初始化器可能会花费大量时间）。
