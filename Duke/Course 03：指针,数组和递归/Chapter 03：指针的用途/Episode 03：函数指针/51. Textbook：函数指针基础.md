# Function Pointer Basics
# 函数指针基础

你的程序实际执行的指令（当然）是**数字**，它们像程序的数据一样存储在计算机内存中。因此，每条指令都有一个**地址**，就像每份数据都有一个地址一样。由于这些指令有地址，我们可以有指向它们的指针。指向任意指令的指针通常没什么用，但指向函数中第一条指令的指针可能非常有用——我们通常把它简单看作指向函数本身的指针，并称之为**函数指针**（function pointer）。

严格来说，任何函数的名称都是指向该函数的指针（也就是说，`printf` 是指向 `printf` 函数的指针），然而，我们通常不这样看待它们。相反，当我们提到函数指针时，通常指的是指向函数的**变量或参数**。然而，函数名是指向它的指针这一事实，对于初始化这样的变量和/或参数很有用。

函数指针最有用的应用，是能够把函数指针作为我们正在编写的函数（或库提供的函数）的**参数**。为了说明这个功能，考虑上图中的四段非常相似的代码。这些函数中的每一个都对一个（`int` 的）数组的每个元素做某件事——它们之间唯一的区别是对每个元素**做什么**。

与其复制代码——每次都重写整个函数——更好的做法是编写一个函数，它接受一个参数来指定“对每一项做什么”。然后，我们可以简单地为每个任务用适当的函数调用那个函数。虽然在这里避免这种代码重复看起来可能不那么重要（函数只有几行长），但当你编写操作更复杂数据结构的更复杂函数时，这种考虑会变得重要得多。

我们可以通过传入一个函数指针作为参数来实现这种行为，该参数指定“对每一项做什么”。

```c
void doToAll(int * data, int n, int (*f)(int)) {
  for (int i = 0; i < n; i++) {
    data[i] = f(data[i]);
  }
}
```

这个例子中的大部分代码应该看起来很熟悉，除了看起来有点奇怪的参数声明：`int (*f)(int)`，它声明了一个参数（称为 `f`），其类型是“一个指向接受 `int` 作为参数并返回 `int` 的函数的指针”。函数指针声明有点不寻常，因为参数（或变量——声明的语法相同）的名称位于声明的**中间**。然而，这个语法是有道理的，因为它看起来很像普通的函数声明——返回类型在前，然后是名称，然后是括号中的参数。不过这里，我们只需要指定参数类型；不需要给它们命名。注意 `*f` 周围的括号很重要——没有它们，`*` 会成为返回类型的一部分（也就是说，`*` 被读作 `int*` 的一部分），声明看起来就像在描述一个返回 `int*` 的函数。有时括号和 `*` 都可以省略（写成 `int f(int)`），然而，通常最好保持一致（并避免试图记住何时允许这样做；我们提到它以防你看到）。

与其他类型一样，我们可以对函数指针使用 `typedef`。语法再次更像函数声明，而不是其他形式的 `typedef`。我们可以重写前面的例子以使用 `typedef`，这样更易读：

```c
typedef int (*int_function_t)(int);
 	
void doToAll(int * data, int n, int_function_t f) {
  for (int i = 0; i < n; i++) {
    data[i] = f(data[i]);
  }
}
```

一旦我们定义了这个 `doToAll` 函数，我们就可以通过传入一个指向适当类型的任何函数的指针来使用它（即，一个接受 `int` 并返回 `int` 的函数）。由于函数名是指向它的指针，我们可以直接写我们想使用的函数名，作为该参数传入的值：

```c
int inc(int x) {
  return x + 1;
}
int square(int x) {
  return x * x;
}
…
doToAll(array1, n1, inc);
…
doToAll(array2, n2, square);
```

我们要注意，你可能会看到这类写法带取地址运算符，例如 `doToAll(array1, n1, &inc)`。这种语法是合法的，但 `&` 是**多余**的，就像数组名一样——函数名本身已经是指针。注意，如果我们有一个不是函数名的函数指针（即变量或参数），那么我们可以取那个变量的地址，得到指向函数指针的指针。最好只在后一种情况下使用取地址运算符，而这种情况相当少见。
