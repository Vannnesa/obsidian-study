# 字符串相等性

程序员常常想比较两个字符串，看看它们是否相等。我们的第一反应可能是使用我们已经见过的 `==` 运算符。然而，`==` 运算符比较的是**指针相等性**。也就是说，如果我们写 `str1 == str2`，它会检查 `str1` 和 `str2` 是否是**指向同一位置**的箭头。有时我们确实想表达指针相等，但更常见的情况是，我们想检查两个字符串是否具有**相同的字符序列**，即使它们在内存中的位置不同。这个概念如下图所示：

![[Pasted image 20260919101755.png]]

这张图说明了，对两个“字符串”应用 `==` 运算符，只是比较指针是否相等。

你可以编写一个函数来测试两个字符串是否具有相同的内容——也就是说，它们是否包含完全相同的字符序列。我们将在下一个视频中走完**七步**来设计和实现这样一个函数。这个任务非常常见，以至于 C 库的 `string.h` 中已经有一个函数可以做到——叫做 `strcmp`。然而，用**七步**走完整个过程，仍然是编写操作字符串代码的一个很好的例子。

C 库的 `strcmp` 函数的行为与我们即将在视频中编写的函数略有不同——如果字符串相等，它返回 `0`；如果不同，则返回**非零**。事实上，如果第一个字符串“**大于**”第二个字符串，它返回一个**正数**；如果第一个字符串“**小于**”第二个字符串，它返回一个**负数**。这里的“大于”和“小于”指的是**字典序**（lexicographic order）——你可以把它理解为“字母顺序”，但扩展到了包含非字母字符的情况。这种比较是**区分大小写**的（所以 `abc` 与 `Abc` 不同），但还有另一个函数 `strcasecmp`，它执行**不区分大小写**的比较。
