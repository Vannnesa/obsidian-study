# getline

你已经见过 `fgets`，它让你把一个字符串读入你预先分配好的缓冲区中，并指定要读取的字符串的最大大小（也就是缓冲区中有多少空间）。然而，你如何编写代码来读取**任意长度**的字符串呢？在本章之前，我们还没有工具来思考这样的函数——它显然需要**动态分配**，因为我们需要该函数分配在函数返回后仍然存在的内存。现在，我们可以学习 `getline` 了。

`getline` 是 C 标准 I/O 库中可用的 C 函数（`#include <stdio.h>`）。它的签名（如下所示）看起来有点吓人，但值得理解。

![[Pasted image 20260921164045.png]]

```c
ssize_t getline(char **linep, size_t *linecapp, FILE *stream);
```

`getline` 从它的第三个参数 `stream` 指定的文件中读取**一行**。它通过反复从文件中读取字符来实现这一点，直到看到字符 `'\n'`，它表示一行的结束。在读取每个字符时，它把字符复制到内存中的**缓冲区**里。读完换行字符后，`getline` 会放置一个 `'\0'` 字符，表示字符串的结束。

到目前为止，这种行为听起来很像 `fgets`；然而，区别在于 `getline` 会**根据需要分配字符串的空间**。这种区别源于 `getline` 使用 `malloc` 和 `realloc` 来分配/扩大缓冲区。参数 `linep` 指向一个指针。如果 `*linep` 是 `NULL`，`getline` 会 `malloc` 一个新的缓冲区。如果 `*linep` 不是 `NULL`，`getline` 会使用那个缓冲区（它有 `*n` 字节长）作为起始。如果初始缓冲区不够长，`getline` 会按需 `realloc` 缓冲区。每当 `getline` `malloc` 或 `realloc` 缓冲区时，它都会更新 `*n` 以反映分配的字节数。它还会更新 `*linep` 以指向新缓冲区。当 `getline` 函数返回时，`*linep` 是指向从文件读取的字符串的指针。

`getline` 函数在出错时（包括文件末尾）返回 `-1`，成功时返回读取的字节数（不包括空终止符字节）。注意返回类型是 `ssize_t`，它代表“**signed size_t**”——也就是说，与 `size_t` 字节数相同的有符号整数类型（因此它可以返回 `-1`）。

`getline` 函数可以以两种方式使用。第一种，用户可以向 `getline` 提供一个指向 `malloc` 分配的缓冲区的指针 `*linep`，其大小由 `linecapp` 指向。如果要读取的行大于 `*linecapp`，`getline` 会为用户执行 `realloc`，并相应地修改 `*linep` 的值（指向新 `realloc` 的区域）和 `*linecapp` 的值（成为新分配缓冲区的大小）。第二种，用户可以不给 `getline` 提供缓冲区，通过 `linep` 包含一个指向 `NULL` 的指针来表示（`linep` 不能是 `NULL`，但 `*linep` 可以是 `NULL`）。在这种情况下，`getline` 会为用户执行 `malloc`，并相应地修改 `*linep` 的值（指向新 `malloc` 的区域）和 `*linecapp` 的值（成为新分配缓冲区的大小）。这两种方式可以一起使用——也就是说，可以编写一个循环，第一次不提供缓冲区，而在后续迭代中重用同一个缓冲区。
