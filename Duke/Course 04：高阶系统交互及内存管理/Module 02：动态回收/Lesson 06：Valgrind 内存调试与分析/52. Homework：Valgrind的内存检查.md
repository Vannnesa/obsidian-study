````quiz
一位 C 程序员编写了以下代码，试图读取多行数字、对它们排序并打印结果。然而，这段代码存在多种与内存相关的错误。

Invalid write of size 8

at 0x4C2AB80: malloc (in ...)
by 0x4C2CF1F: realloc (in ...)
by 0x400759: main (broken.c:15)
```

以下哪一项最好地描述了 Valgrind 观察到的无效行为？

Valgrind 报告的是 `Invalid write of size 8`，发生在 `broken.c:16`，说明第 16 行试图写入 8 字节到无效内存。
````

````quiz
## 问题 2
在上一题中，valgrind 错误消息的最后一部分说：

```text
Address 0x51fc108 is 0 bytes after a block of size 8 alloc'd
at 0x4C2AB80: malloc (in ...)
by 0x4C2CF1F: realloc (in ...)
by 0x400759: main (broken.c:15)
```

Valgrind 不仅报告了无效地址是 `0x51fc108`，还说它“在一个大小为 8 的已分配块之后 0 字节处……”

Valgrind 用这部分错误消息提供了什么信息？

[ ] 这个指针实际上指向栈，但程序试图把它传给 `realloc`。
[ ] 程序在尝试调用 `malloc` 时耗尽了内存。
[ ] 无效地址位于一个由 `malloc` 分配、然后被第 15 行的 `realloc` 调用释放的块内部。
[c] 无效地址紧接在一个大小为 8 的块之后，该块是由这个程序第 15 行的 `realloc` 调用分配的。

Valgrind 指出无效地址位于一个已分配块之后 0 字节处，并给出了分配该块的调用栈（第 15 行的 `realloc`）。
````

````quiz
## 问题 3
根据你从 Valgrind 获得的信息，你会如何修改这个程序来修复前两题中讨论的错误？

[ ] 将第 16 行改为：
```c
array[n-1] = strtol(line, NULL, 0);
```
[ ] 将第 12 行改为将 `n` 初始化为 1 而不是 0：
```c
size_t n = 1;
```
[c] 将第 14 行移到第 15 行之后：
```c
array = realloc(array, n * sizeof(*array));
n++;
```
[ ] 将第 15 行改为使用 `malloc` 而不是 `realloc`：
```c
array = malloc(array, n * sizeof(*array));
```

错误是因为在 `realloc` 分配空间之前就递增了 `n`，导致写入越界。正确的顺序应该是先递增 `n`，再 `realloc`，然后写入 `array[n-1]`。
````
