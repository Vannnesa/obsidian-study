# Other Valgrind Tools
# 其他 Valgrind 工具

Memcheck 并不是 Valgrind 中唯一的工具——尽管它是最常用的工具之一，也是许多人听到“Valgrind”时首先想到的东西。随着你成为更高级的程序员，你可能会发现使用其他一些工具很有用。我们不会深入探讨它们，但会提到几个存在的工具，以便你在需要时知道去进一步探索它们。

多线程编程中会出现各种各样的问题，例如由于获取锁的顺序不当导致的**死锁**、**数据竞争**，或同步原语的不当使用。你还应该知道，由于多线程执行的**非确定性行为**，这些问题可能很难发现——一个 bug 可能这次显现，但接下来的上百次运行中都不再出现。Valgrind 工具 **Helgrind** 就是用来检查各种与多线程编程相关的错误的。更多细节请参见  
http://valgrind.org/docs/manual/hg-manual.html 。

Valgrind 的工具不仅限于帮助你发现程序中的**正确性 bug**，还可以帮助理解**性能**和**内存使用**问题。例如，**Callgrind** 工具基于 Valgrind 在执行程序时对硬件资源的模拟，给出程序的性能特征信息。另一个工具是 **Massif**，它分析堆中的动态内存分配，并给出任意给定时刻分配了多少内存，以及内存是在代码中的哪里分配的。

参见  
http://valgrind.org/info/tools.html  
以了解这些工具的概览。还要注意，许多其他工具也有头文件，你可以包含它们，其中带有允许你的程序直接与 Valgrind 交互的宏（类似于 `memcheck.h` 中的功能）。
