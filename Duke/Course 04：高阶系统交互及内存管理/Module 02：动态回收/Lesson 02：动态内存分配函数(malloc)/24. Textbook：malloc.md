# malloc

动态内存分配最基础的函数叫做 `malloc`（即 memory allocation，内存分配）。调用这个函数就是你**动态分配内存**的方式。`malloc` 函数（如下图）接受一个参数，告诉它需要多少内存，并以 `void *` 的形式返回一个指向那块已分配内存的指针。

许多初学者会被 `void *` 这个概念吓到，但你不应该害怕！回想一下，`void *` 只是表示一个指针，但我们不知道它指向的是什么类型的东西。如果 `malloc` 返回的是更具体的类型（例如 `int *`），那么我们就需要为每一种数据类型都准备一个 `malloc` 版本。这既笨重，而且（在用户自定义数据类型的背景下）是不可能的。只需记住，你可以把 `void *` 赋给任何其他指针类型——所以只需把 `malloc` 的返回结果赋给你想要初始化的任何指针即可。
