# 修复 initArray

有了 `malloc` 供我们使用，我们终于能够正确实现本章开头介绍的任务：

```c
// 这段代码可以工作！
int * initArray(int howLarge) {
  int *array = malloc (howLarge * sizeof(*array));
  if (array != NULL) {
    for (int i =0; i < howLarge; i++) {
      array[i] = i;
 	  }
 	}
 	return array;
}
```

注意，在这个函数中，如果 `malloc` 失败（即返回 `NULL`），那么函数返回 `NULL`——这把处理错误的任务**推给**了调用这个函数的代码。每当你编写一个函数，而你不知道错误应该如何处理时，**让调用者处理错误是一个好策略**。
