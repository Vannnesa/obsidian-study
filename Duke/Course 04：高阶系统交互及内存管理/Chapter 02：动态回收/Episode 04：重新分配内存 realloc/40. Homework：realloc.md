## 问题 1
`realloc` 做什么？

[ ] 重复之前的分配请求。
[ ] 回收之前分配的内存块。
[c] 调整之前分配的内存块的大小。
[ ] 重试之前失败的分配。

`realloc` 用于重新调整由 `malloc`、`calloc` 或 `realloc` 分配的现有内存块的大小，可能将其移动到堆中的新位置。

````quiz
## 问题 2
假设你有以下代码：

```c
int * p = malloc(12*sizeof(*p));
char * q = malloc(14*sizeof(*q));
char * m = q;
q++;
int ** ptr= &p;
```

上面代码中哪些指针可以作为第一个参数传给 `realloc`？（选择所有适用项。）

[c] `p`
[ ] `q`
[c] `m`
[ ] `ptr`

只有指向由 `malloc` 分配的内存块**起始地址**的指针才能传给 `realloc`。`p` 是原始返回的指针；`m` 保存了 `q` 在递增前的原始值；`q` 已经递增，不再指向块起始；`ptr` 是指向指针的指针，不是堆内存块的起始地址。
````
