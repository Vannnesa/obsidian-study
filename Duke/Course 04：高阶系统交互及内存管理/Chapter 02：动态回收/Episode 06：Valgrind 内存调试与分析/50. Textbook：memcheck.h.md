# memcheck.h

有时我们可能想在程序中**直接与 Valgrind 的工具交互**。例如，我们可能想显式检查某个值在程序的某个点是否已初始化（例如，作为调试未初始化值错误的一部分）。Valgrind 提供了头文件，例如 `memcheck.h`，其中包含各种**宏**，正是用于这个目的。例如，我们可以把之前用作未初始化值示例的函数改成：

```c
void f(int x) {
  int y;
  int z = x + y;
  VALGRIND_CHECK_MEM_IS_DEFINED(&z,sizeof(z));
  printf("%d\n", z);
}
```

现在，当我们在 valgrind 中运行这个程序时，我们会**更早地**得到错误消息：

```text
==12425== Uninitialised byte(s) found during client check request
==12425==    at 0x4007C9: f (uninit4.c:8)
==12425==    by 0x400811: main (uninit4.c:17)
==12425==  Address 0xfff000410 is on thread 1's stack
==12425==  Uninitialised value was created by a stack allocation
==12425==    at 0x400765: f (uninit4.c:5)
```

Memcheck 的许多功能都可以通过这些**宏**使用。大多数其他工具也有类似的头文件，供程序直接与它们交互。参见  
http://valgrind.org/docs/manual/mc-manual.html#mc-manual.clientreqs  
以获取更多细节。
