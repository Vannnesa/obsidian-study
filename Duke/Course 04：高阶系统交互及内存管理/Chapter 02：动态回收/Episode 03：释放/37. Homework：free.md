````quiz
## 问题 1
`free(p)` 做什么？

[ ] 减少访问 `p` 的运行时开销
[c] 释放 `p` 所指向的内存块
[ ] 从栈帧中移除 `p`
[ ] 把 `p` 复制到新位置

`free` 用于释放由 `malloc` 分配的堆内存，它接受一个指针，释放该指针指向的内存块。它不会改变指针本身，也不会影响栈帧。
````

````quiz
## 问题 2
假设你有以下代码：

```c
int * p = malloc(sizeof(int));
int * q = p;
free(p);
free(q);
```

这段代码在 `free` 的使用上存在什么问题？

[ ] 这段代码泄漏内存
[ ] 这段代码释放了不是由 `malloc` 返回的内存块
[c] 这段代码双重释放了一个内存块
[ ] 以上都不是：这段代码正确使用了 `free`

`p` 和 `q` 指向同一块内存，`free(p)` 之后该块已被释放，再 `free(q)` 就是双重释放，会导致未定义行为（通常崩溃）。
````

````quiz
## 问题 3
假设你有以下代码：

```c
int xcount = 0;
char * ptr = malloc(50 * sizeof(char));
if (fgets(ptr, 50, stdin) != NULL) {
  while(*ptr != '\0') {
    if (*ptr == 'x') {
      xcount++;
    }
    ptr++;
  }
}
```

这段代码在 `free` 的使用上存在什么问题？

[c] 这段代码泄漏内存
[ ] 这段代码释放了不是由 `malloc` 返回的指针
[ ] 这段代码双重释放了一个内存块
[ ] 以上都不是：这段代码正确使用了 `free`

代码分配了内存，但 `ptr` 在循环中被递增，原始指针丢失，且从未调用 `free`，因此造成内存泄漏。
````

````quiz
## 问题 4
`free(NULL)` 做什么？

[ ] 释放所有不可达的内存块
[ ] 释放所有由 `malloc` 分配的内存
[ ] 使程序崩溃
[ ] 释放最近分配的内存块
[c] 什么也不做

`free(NULL)` 是安全的，它不执行任何操作。C 标准规定，如果参数是空指针，`free` 不产生任何效果。
````
