getline(&line, &sz, stdin);

[ ] malloc 一个实现特定大小的空间。
[ ] 使用 `fgets` 确定要 malloc 多少字节空间，然后 malloc 那么多空间。
[ ] malloc `4 * sizeof(char)` 字节的空间。
[ ] malloc 4 字节的空间。
[c] malloc 一个实现特定大小的空间。

当 `*linep` 为 `NULL` 时，`getline` 会忽略 `*linecapp` 的初始值，自行 malloc 一个实现定义的初始缓冲区大小。

## 问题 2
假设你有以下代码（与问题 1 的代码略有不同）：

```c
size_t sz = 4; 
char * line = malloc(42 * sizeof(*line));
getline(&line, &sz, stdin);
```

第 3 行的 `getline` 调用会假设它有多少可用空间来从 `stdin` 读取字符？

[ ] 它会假设至少有下一行从 `stdin` 读取的长度那么多的字节。
[c] 它会假设至少有 4 字节。
[ ] 它不会做任何假设，而是使用 `sizeof` 来确定有 42 字节可用。

`getline` 使用 `*linecapp` 指向的值作为当前缓冲区大小，因此它会认为只有 `sz`（即 4）字节可用，尽管实际分配了 42 字节。

## 问题 3
假设你有以下代码（与前几个问题的代码略有不同）：

```c
size_t sz = 0; 
char * line = NULL;
getline(&line, &sz, stdin);
```

进一步假设，当你的程序调用 `getline` 时，用户输入：

```text
Hello
```

（包括换行字符）。

在 `getline` 调用返回后，以下关于 `sz` 的哪一项为真？

[ ] `sz` 将等于 6
[ ] `sz` 将等于 7
[ ] `sz` 将至少为 6
[c] `sz` 将至少为 7

`getline` 会分配足以存储 `"Hello\n\0"` 的内存，至少需要 7 字节，并且会把分配的实际容量写入 `*linecapp`，因此 `sz` 至少为 7。
