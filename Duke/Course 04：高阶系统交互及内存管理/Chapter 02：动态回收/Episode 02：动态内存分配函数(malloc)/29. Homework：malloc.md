````quiz
## 问题 1
`malloc` 在哪里分配内存？

[c] 在堆（heap）上
[ ] 在代码段（text segment）中
[ ] 在数据段（data segment）中
[ ] 在栈（stack）中

`malloc` 用于**动态内存分配**，分配的内存在**堆**上，函数返回后仍然有效，需要显式用 `free` 释放。
````

````quiz
## 问题 2
`malloc` 的原型是什么？

[ ] `const int * malloc(int size);`
[ ] `void * malloc(int size);`
[ ] `const void * malloc(size_t size);`
[c] `void * malloc(size_t size);`
[ ] `const int * malloc(unsigned int size);`

`malloc` 接受一个 `size_t` 类型的字节数，返回一个 `void *`，可以赋给任何指针类型。
````

````quiz
## 问题 3
假设你想让 `p` 指向一个由 `malloc` 分配的包含 16 个 `int` 的数组。以下哪种是声明并初始化 `p` 的最佳方式？

[ ] `int * p = malloc(64);`
[ ] `int * p = malloc(16 * sizeof(int));`
[c] `int * p = malloc(16 * sizeof(*p));`
[ ] `int * p = malloc(16 * 4);`

`sizeof(*p)` 表示 `p` 所指向类型的大小，这样写不依赖具体类型，更通用、更安全；而 `sizeof(int)` 或硬编码 `64`、`16*4` 可读性和可移植性较差。
````
