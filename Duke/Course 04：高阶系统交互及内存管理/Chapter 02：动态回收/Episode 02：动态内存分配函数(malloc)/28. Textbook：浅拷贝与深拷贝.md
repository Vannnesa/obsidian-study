# Shallow vs. Deep Copying
# 浅拷贝与深拷贝

假设我们有一个 `polygon_t * p1` 指向我们创建的一个多边形（例如通过调用 `makeRectangle`），我们想复制它指向的多边形。如果我们只是写下面这样，我们只复制了**指针**——我们并没有真正复制它指向的对象：

```c
polygon_t * p2 = p1; // 只是复制指针
```

下图说明了这条语句的效果（希望你现在已经熟悉了）。把指针 `p1` 赋给指针 `p2` 之后，两者都指向**完全相同的内存位置**。唯一新创建的盒子是指针 `p2` 的盒子，如果我们通过一个指针改变多边形的任何内容，通过另一个指针检查值时也会看到这个改变——因为它们指向相同的值。

![[Pasted image 20260921162618.png]]

如果我们使用 `malloc`，就可以创建一个副本。例如，我们可能写：

```c
polygon_t * p2 = malloc(sizeof(*p2));
*p2 = *p;
```

下图说明了这段代码的效果。

![[Pasted image 20260921162628.png]]

现在，我们有两个多边形，但只有**一个点数组**。我们创建了这个多边形的**浅拷贝**（shallow copy）——我们通过精确复制多边形内部的字段来制作它的副本。浅拷贝中的每个指针都指向与原始对象中对应指针**完全相同的内存位置**。在某些情况下，浅拷贝可能正是我们想要的。然而，如果我们执行 `p1->points[0].x = 42;`，我们就会改变 `p2` 第 0 个点的 `x`，因为 `p1->points` 和 `p2->points` 指向相同的内存。注意，在释放一个被浅拷贝过的对象时也必须小心——我们需要确保只有在两个浅拷贝都用完时才释放点数组。由于它们共享内存，如果我们在用完一个时就释放点数组，然后试图使用另一个副本，它就会有一个**悬空指针**。

如果我们想要两个完全独立的多边形对象，我们就需要制作**深拷贝**（deep copy）——在深拷贝中，我们不只是复制指针，而是为指针指向的任何东西分配新内存并制作深拷贝。要制作我们的 `polygon_t` 的深拷贝，我们会写：

```c
polygon_t * p2 = malloc(sizeof(*p2));
p2->num_points = p1->num_points;
p2->points = malloc(p2->num_points * sizeof(*p2->points));
for (size_t i = 0; i < p2->num_points; i++) {
  p2->points[i] = p1->points[i];
}
```

下图说明了这段代码的深拷贝效果（同样，这应该不会令人惊讶——一如既往，它遵循你学过的相同规则）。
![[Pasted image 20260921162639.png]]

这里我们创建了两个完全独立的多边形，它们的点具有相同的值，但有**自己的内存**。如果我们改变一个多边形的点的 `x` 或 `y`，另一个不受影响，因为它们是两个完全独立的数据结构。同样，我们现在可以在用完一个多边形后完全释放它，而无需担心其他东西共享它的内部结构。
