# More Complex Structures
# 更复杂的结构

虽然我们目前的例子展示了用 `malloc` 分配 `int` 数组，但我们当然可以用 `malloc` 分配任何想要的类型。如果需要，我们可以为**某一个东西**（而不是数组）分配内存，或者分配任意数量的东西（只要内存允许）。我们可以通过用 `malloc` 分配带有指针的 `struct`，然后让这些指针指向堆中的其他位置（这些位置本身又指向由 `malloc` 分配的块），从而在堆中形成**复杂的数据结构**。我们明确说明这一点，因为它很重要；然而，你也可以意识到，所有这些之所以可能，是因为**可组合性**（composability）原则——我们可以把所有这些不同的部分组合在一起，构成更大的东西。

例如，我们可能写：

```c
struct point_tag {
  int x;
  int y;
};
typedef struct point_tag point_t;

struct polygon_tag {
  size_t num_points;
  point_t * points;
};
```

这里，我们有一个函数，它为一个多边形（一个 `struct`）用 `malloc` 分配空间，而这个结构体本身有一个指向点数组的指针。这个特定的函数创建一个矩形，所以它为 4 个点用 `malloc` 分配空间，并在把答案返回给调用者之前填充它们。
