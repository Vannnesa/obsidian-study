````quiz
## 问题 1
如何知道对 `fopen` 的调用失败了？

[ ] 如果 `fopen` 失败，它会调用 `exit(EXIT_FAILURE)`。
[c] 如果 `fopen` 失败，它会返回 `NULL`。
[ ] 如果 `fopen` 失败，它会打印一条错误消息。
[ ] 如果 `fopen` 失败，你的程序会发生段错误。

`fopen` 失败时返回 `NULL`，并适当地设置 `errno`。在尝试使用流之前，应始终检查其返回值是否为 `NULL`。
````

````quiz
## 问题 2
假设你写了以下代码：

```c
FILE * f = fopen("myfile.txt", "r");
```

并且这次 `fopen` 调用成功了。在这次 `fopen` 调用之后，`f` 的当前位置是什么？

[ ] 未定义。
[c] 文件开头。
[ ] 文件末尾。
[ ] `strlen("myfile.txt")`
[ ] `strlen("myfile.txt") + 1`

模式 `"r"` 以只读方式打开文件，流的当前位置位于文件开头。
````

````quiz
## 问题 3
假设你有：

```c
x = fgetc(f);
```

`x` 的正确类型是什么？

[ ] `char`
[ ] `unsigned char`
[ ] `const char *`
[ ] `size_t`
[ ] `unsigned int`
[ ] `int *`
[c] `int`

`fgetc` 返回 `int`，以便能返回从文件读取的任何可能字符值，以及一个独特的表示文件末尾的 `EOF` 值。
````
