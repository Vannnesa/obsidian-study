# Complex Option Processing
# 复杂选项处理

有些程序会执行更**复杂的选项处理**——接受各种各样的标志和选项，其中一些需要参数（在某些情况下是可选参数）。回到我们的 `gcc` 例子，当我们写：

```bash
gcc -o myProgram myProgram.c
```

`-o` 选项本身接受一个参数——紧跟在它后面的下一个命令行参数指定了输出是什么，因为 `-o` 就在它前面。然而，`gcc` **并不要求** `-o` 必须出现在这个位置，我们可以先写其他参数。

对于更复杂的选项处理（例如像 `gcc` 这样的程序所需要的），**`getopt` 函数**相当流行。`getopt` 是 C 库的一部分，它解析命令行参数，并考虑诸如带有（可能是可选的）参数的选项，以及**短名称和长名称**版本（例如，有些程序可能接受短名称如 `-o`，以及长名称如 `--output`，含义相同）。我们这里不深入 `getopt` 的细节，但如果你需要它，当然可以在它的 man 页面中阅读（务必指定 `man -S3 getopt`，因为 man 页面**第 1 节**中有一个同名的程序）。
