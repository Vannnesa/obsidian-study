# Problem Description
# 问题描述

为了看到所有这些概念的实际应用，我们将详细考虑一个中等规模的编程示例（我们要注意，从宏观来看，这仍然是一个相当小的程序）。

编写一个程序 `roster`，它读取一个具有以下格式的文件：

```text
Number of students
Student Name
Number of classes
Classname 1
Classname 2
...
Classname N
Student Name
Number of classes
Classname 1
```

也就是说，第一行包含一个整数，表示文件中描述的学生人数。之后是学生描述，每个学生描述都以一行包含学生姓名的内容开始。下一行是该学生所上课程的数量。之后有指定数量的行，每行包含一个课程名称。你的程序应该读入这个文件，然后输出每个课程的**课程名册**。具体来说，对于每个课程，它应该创建一个名为 `classname.roster.txt` 的文件（其中 `classname` 是课程名称），并把该课程中的所有学生（每行一个）打印到该文件中。

例如，如果你的输入文件是：

```text
4
Orpheus
3
Mus304
Lit322
Bio419
Hercules
2
Gym399
Lit322
```

注意，如果文件不遵守此格式，你的程序应该向 `stderr` 打印一条有意义的错误消息，并以失败状态退出。

这个问题太大，无法作为单个函数来编写。做好这个任务需要把它分解成大约十几个函数。我们可以直观地看到分解的必要性，只需观察我们需要执行几个离散的任务：读取输入（它本身还有更小的子任务，例如带错误检查地读取一个数字，以及读取一个学生的信息）、“重新排列”信息为我们需要的格式、写入输出（它本身还有更小的子任务，例如计算某个课程的文件名，以及写出某个课程的信息），以及释放我们读取输入时分配的内存。
