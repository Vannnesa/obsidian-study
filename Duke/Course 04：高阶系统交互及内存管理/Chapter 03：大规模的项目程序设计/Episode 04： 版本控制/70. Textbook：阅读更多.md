# 阅读更多

希望我们已经向你展示了版本控制的一些巨大好处，我们推荐进一步阅读关于 Git 的在线书籍：  
http://git-scm.com/book/en/v2/

在我们看来，阅读（尝试并理解）前两章是“**必修**”的，即使对那些只是随便对学习编程感兴趣的人也是如此。我们建议任何软件开发课程都通过版本控制来运作——通过把作业放入学生可以拉取的仓库来分发作业，并让学生通过提交和推送他们的更改来提交作业（就像你在本专项课程中所做的那样）。

如果你对严肃的软件开发感兴趣，你应该掌握这门课程，然后随着你发展其他编程技能，继续磨练你的 Git 技能。随着时间的推移，你应该学习本课程之外的材料，并努力流畅地使用 Git。
