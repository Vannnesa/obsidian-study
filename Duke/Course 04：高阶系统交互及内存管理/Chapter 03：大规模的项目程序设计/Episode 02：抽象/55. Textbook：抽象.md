# Abstraction
# 抽象

设计任何大型系统的关键技术之一就是**抽象**（abstraction）。正如我们之前讨论的，抽象是**接口与实现的分离**。某事物的**接口**（interface）是它**做什么**，而**实现**（implementation）是它**如何做**。

考虑这个抽象的例子：驾驶汽车与了解汽车引擎盖下如何工作。汽车提供了一个简单的接口（转动方向盘会让汽车转向，踩油门会让汽车加速，踩刹车会让汽车减速……）。然而，其实现（引擎盖下一切如何工作）相当复杂。当然，你实际上不需要知道汽车如何工作就能驾驶它——**实现对你隐藏**。你只需要知道接口。

类似的原则也适用于程序设计——**如果你知道一个函数做什么，就应该能够使用它，而不必知道它是如何做到的**。事实上，在你迄今为止的编程中，你已经例行使用了各种各样的 C 库函数，而不了解它们的实现细节（即使是那些你可能作为练习写过等价实现的函数，在真正的 C 库中也可能以优化得多的方式实现）。
