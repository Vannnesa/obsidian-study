# Reading a File
# 读取文件

一旦我们打开了文件，就可能想从中读取输入。我们通常会使用三个函数之一来做到这一点：`fgetc`、`fgets` 或 `fread`。其中，`fgetc` 在你想要一次读取一个字符（例如字母）时很有用。这个函数有以下原型：

```c
int fgetc(FILE * stream);
```

虽然你可能期望这个函数返回 `char`，但它返回 `int`，这样它就能返回所有可能的 `char`，再加上一个**独特的值**来表示流中不再有字符可用——即已经到达**文件末尾**（end of file，**EOF**）。文件末尾的值在 `stdio.h` 中定义为常量 `EOF`。注意，读取字符会**推进流中的当前位置**。

从流中读取的函数会推进流的位置，这一事实在编写循环时会带来一点小麻烦。考虑以下（坏掉的）代码，它试图打印输入文件中的每个字符：

```c
// 坏掉的
FILE * f = fopen(inputfilename, "r");
if (f == NULL) { /* 省略错误处理代码 */ }
while (fgetc(f) != EOF) {
  char c = fgetc(f);
  printf("%c",c);
}
//...其他代码...
```

这段代码会读取一个字符，检查它是否是文件末尾，然后读取**另一个**字符并打印它。这段代码实际上会打印输入文件中的**每隔一个字符**，再加上末尾可能出现的多余内容（如果文件中的字符数是奇数）。

重新组织这个循环最干净的方式，是利用**赋值也是一个表达式**这一事实——它求值为被赋的值。虽然这听起来像是一句技术性很强的拗口话，但它的意思是：`x = 3` 不仅是把 `3` 赋给 `x`，也是一个求值为 `3` 的表达式。因此我们可以写 `y = x = 3`，把 `3` 同时赋给 `x` 和 `y`——然而，我们通常不这样做，因为它比写两条赋值语句更不清晰。不过在这个特定情况下，利用赋值的这个性质是可以的，而且实际上是一种常见的**惯用法**。以下代码正确地打印输入文件中的每个字符：

```c
// 修复后
FILE * f = fopen(inputfilename, "r");
if (f == NULL) { /* 省略错误处理代码 */ }
int c;
while ( (c=fgetc(f)) != EOF ) {
  printf("%c",c);
}
//...其他代码...
```

观察我们如何在 `while` 循环的条件表达式中把 `fgetc` 的结果赋给变量 `c`。然后我们把那条赋值语句用括号包起来，以确保正确的运算顺序，并把被赋的值（即 `fgetc` 返回的任何值）与 `EOF` 比较。

你可能注意到 `c` 的类型是 `int`，而不是 `char`。如果我们把 `c` 声明为 `char`，我们的程序就会有一个相当**微妙的 bug**。你能发现它吗？记住，我们说过 `fgetc` 返回 `int`，这样它就能返回从文件中读取的任何可能字符值，再加上某个表示 `EOF` 的独特值。把这个返回值赋给 `char` 本质上会**丢弃信息**——我们把 N + 1 个可能的值赋给一个只能容纳 N 种不同位模式的东西（对于 `char`，N = 256）。在大多数系统上，`EOF` 是 `–1`，所以在这个特定情况下，我们将无法区分读取字符编号 255 和文件末尾——如果我们的输入中有字符编号 255，我们的程序就会**过早退出循环**，忽略输入的其余部分！你在编写测试用例时，应该努力思考这类**边界情况**。
