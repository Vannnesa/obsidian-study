# Reading a File with fgets
# 使用 fgets 读取文件

当你想要一次读取**一行**（有最大长度限制）时，`fgets` 函数很有用。这个函数有以下原型：

```c
char * fgets(char * str, int size, FILE * stream);
```

这个函数接受三个参数。第一个是指向一个数组的指针，用于存储从文件读取的字符。也就是说，`fgets` 会把数据写入 `str[0]`、`str[1]`、`str[2]`…… 第二个参数指定它有多少空间可以写入数据。也就是说，`size` 指定了数组 `str` 的大小。最后一个参数指定从哪个**流**读取数据。

如果成功（无错误地读取数据），这个函数返回 `str`，此时 `str` 中的数据以**空终止符**结尾。如果失败，它返回 `NULL`——要么是在读取任何数据之前就遇到了**文件末尾**，要么是遇到了其他错误。如果你需要区分错误和文件末尾，应该使用 `feof` 和/或 `ferror` 函数，它们分别指定是否有东西试图读过文件末尾、或者是否发生了其他错误（详情见它们的 man 页面）。

现在正是再次提醒的好时机：**你永远不应该使用 `gets` 函数**。这个函数的行为与 `fgets` 有些类似，但它**不接受**指定所读入数组大小的参数。这个疏忽意味着它会一直读取数据直到遇到换行符，即使它写越过了数组的边界（它无法知道数组有多大）。因此，`gets` 函数构成了重大的**安全漏洞**，因为它容易受到**缓冲区溢出**的攻击。
