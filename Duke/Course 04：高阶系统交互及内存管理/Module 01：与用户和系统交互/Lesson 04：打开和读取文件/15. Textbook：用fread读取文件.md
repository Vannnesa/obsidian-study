# Reading a File with fread
# 使用 fread 读取文件

我们可能还想从文件中读取**非文本数据**。例如，我们可能有一个图像、视频、声音或其他文件，其中我们以**二进制格式**写入数据。在这样的文件中，不是写入整数的文本表示，而是把整数的实际字节写入文件。每份数据所用整数的具体大小是**文件格式规范**的一部分。当我们想以这种方式读取数据时，最合适的函数是 `fread`，它有以下原型：

```c
size_t fread (void * ptr, size_t size, size_t nitems, FILE * stream);
```

第一个参数是指向要写入的数据的指针——它是 `void *`，因为它可以是任何类型的数据。下一个参数指定每个**项**的大小。也就是说，如果我们要读写一个 `int` 或一个 `int` 数组，我们会传入 `sizeof(int)`。然而，如果我们在读写文件，我们可能想使用 `stdint.h` 中定义的 `int` 类型，它们的大小在不同系统间是**固定的**（例如 `int32_t` 或 `uint64_t`）。第三个参数指定应该从流中读取多少个这样的项，最后一个参数指定从哪个流读取。`fread` 函数返回成功读取了多少个项。与 `fgets` 一样，如果 `fread` 返回的项数少于你请求的数量，你应该使用 `feof` 和/或 `ferror` 来获取更多信息。

我们要注意，还有一个函数 `fscanf`，它读取**格式化输入**，并以与 `printf` 相反的方式进行转换。如果你需要这个功能，使用 `fgets`（或者我们稍后会看到的 `getline`）然后对得到的字符串使用 `sscanf`，通常更容易处理错误。`fgets`（以及后来的 `getline`）会一次读取一行，然后你可以尝试把结果转换出来，它可能有、也可能没有想要的格式。在这种情况下，你可以轻松地继续读取下一行。相比之下，`fscanf` 一旦遇到与请求格式不匹配的东西就会停止读取输入。如果你想从下一行继续读取，你必须先显式地读出该行的剩余部分，然后才能继续。如果你想了解更多关于 `fscanf` 或 `sscanf` 的信息，请参见它们的 man 页面。
