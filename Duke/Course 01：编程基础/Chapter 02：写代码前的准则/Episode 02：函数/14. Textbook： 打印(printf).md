## 打印
到目前为止，我们的示例程序已经计算出了结果，但却无法将结果传达给用户。这样的程序在实践中毫无用处。真正的程序都有与用户交流的方式，既可以读取输入，也可以提供输出。你习惯使用的许多程序都有图形用户界面（GUI），但我们将主要使用命令行界面的程序。编写图形用户界面是一项更为复杂的任务，需要各种额外的概念。

命令行程序通过在终端上打印输出向用户提供输出。在 C 语言中，打印输出是通过调用**printf** 函数来实现的，该函数接受一个字符串，指定要打印的内容。我们稍后将学习更多关于字符串的知识，因为它们需要指针知识才能理解。现在，你可以把它们看成是文字或句子。就像我们可以写数字字面量（如 3 或 -42）一样，我们也可以写字符串字面量，方法是将我们想要的字符串放在引号内，如 "这是一个字符串"。如果要打印出字符串 "Hello World"，我们可以键入**printf("Hello World");**。

**printf**中的 f 代表 "格式化"，这意味着**printf** 不只是打印字面字符串，还可以接收多个参数（各种类型），将输出格式化为字符串，并打印结果。为了以这种方式格式化输出，**printf**的字符串参数（称为 "格式字符串"）包含以百分号 (%) 开头的特殊格式指定符。目前，我们只关注 %d，它指定整数应格式化为十进制数（基数为 10）。例如，如果我们编写以下代码片段：
````c
int x = 3;
int y = 4;
printf("x + y = %d", x + y);
````
它将打印 x + y = 7，因为它将对表达式 x + y 进行运算，得到 3 + 4，即 7，并将数字 7 格式化为十进制数，以代替 %d 指定符。字符串的其余部分则按字面意思打印。

我们可以在字符串中包含的另一种特殊信息是转义序列。转义序列是两个（或多个）字符，其中第一个字符是反斜线 (\)，它赋予其余字符特殊含义。最常见的转义序列是 \n，意思是 "换行"。如果你想让打印语句打印一个换行符（使下一次输出从下一行开始），就可以用 \n 来实现。如果你想打印一个反斜线字符（也就是说，你实际上想打印一个反斜线字符），那么 \\ 就是实现这一目的的转义序列。我们会注意到，一般情况下，你会希望在输出中打印换行符，这不仅是为了让输出看起来漂亮，而且还因为 printf 在遇到换行符或被迫这样做之前，不会将输出实际打印到屏幕上。
