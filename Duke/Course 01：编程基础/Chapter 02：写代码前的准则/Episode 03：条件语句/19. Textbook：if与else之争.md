## if 还是 else？

关键字 if 后面是括号中的表达式。该表达式将被求值，以决定是执行 "then "代码块还是 "else "代码块。then "代码块紧跟在表达式之后。C 语言没有 then 关键字（尽管有些语言有），但无论语言的语法特性如何，该代码块的作用都是相同的--如果条件表达式的值为 true，则执行该代码块。在 "then "代码块之后是关键字 else，接着是 "else "代码块。如果条件表达式的值为假，则执行该代码块。

当执行箭头到达 if 语句时，对条件表达式进行求值。评估该表达式的过程与评估其他表达式一样。如果结果为 "true"，则立即将执行箭头移到 "then "代码块内，然后像往常一样继续执行语句。当执行到结束 "then "代码块的大括号时，跳过 else 代码块，将执行箭头紧接在 "else "代码块的大括号之后，然后继续执行语句。

如果条件表达式的结果为假，则应跳过 "then "代码块，执行 "else "代码块。将执行箭头移动到 "else "代码块的起始位置，然后从这里开始继续执行语句。当执行箭头到达结束 "else "代码块的大括号时，只需将执行箭头移过大括号（没有任何作用，只是表示代码块的结束），然后继续正常执行语句。

C 语言允许 if 不带 else，这相当于一个空的 "else "块（就像程序员写了 else {}）。如果执行不带 else 的 if，那么只需想象空的 "else "代码块即可。如果条件表达式求值为 true，则应如前所述执行 "then "代码块，但不能跳过 "else "代码块。相反，应在 "then "代码块结束后继续执行语句（跳过不存在的 "else "代码块）。如果条件表达式求值为 false，则跳过 "then "代码块，执行它后面的语句（不执行 "else "代码块）。

if/else 语句可以嵌套，一个（或多个）if/else 语句可以出现在另一个 if/else 语句的 "then "或 "else "块中。遇到嵌套语句时，同样的规则适用。内部语句只是语句块中（可能是）众多语句中的一个，并根据其规则执行--对条件进行求值，执行 "then "或 "else "块中合适的语句，然后在 "else "块结束后继续执行。当执行箭头到达外部 "then "或 "else "代码块的末尾时，其行为与没有内部 if 语句时没有什么不同。下一段视频演示了一些 if/else 语句的执行过程。
