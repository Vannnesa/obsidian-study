## while loop模板
````c
void f(int x, int y){
	while(x < y){
		printf("%d", y - x);
		x = x + 1;
		y = y - 1;
	}
}
````
f(1, 3) = 2

开始：x = 1，y = 3 → 条件 x < y 为真

- 打印 y - x = 3 - 1 = 2
    
- 更新：x = 2，y = 2
    

现在： x = 2，y = 2 → 条件 x < y 为假，因此 Loop 结束。
