## 速记
C 语言（以及许多其他编程语言）_为_各种常用操作提供了速记方法，也称为_语法糖_。这些速记并不引入任何新的行为。相反，它们只是提供了一种更简短的方式来书写我们所见过的现有事物的常见模式。本表显示了 C 语言中最常用的速记符号：
![[语法糖.png]]
这些速记符号与其扩展含义具有完全相同的效果。因此，当你在执行代码时遇到一个速记语句，你可以通过考虑它的完整写出形式来执行它，并执行该语句的效果。

对于将操作与赋值相结合的速记语句（如 *=），如果右侧涉及其他操作，则在扩展速记语句时应将右侧视为括号。 即
````c
x *= y+3；
````
↑的行为就像↓
````c
x = x * ( y +3)；
````

这是因为其目的是将左边（x）乘以右边（y+3），然后赋值给 x。

另一种可能的速记方法是在某些情况下省略单语句代码块周围的大括号。例如，如果 if 语句中的 "then "和/或 "else "子句是一个单独的语句，就不需要大括号。虽然您可能会遇到其他人这样编写代码，但这样编写代码是非常不可取的。省略大括号会给将来修改代码带来危险。如果您在子句中添加了另一条语句，但忘记添加大括号，那么该语句实际上就不是子句的一部分，而是**if** 之后的第一条语句。**最近，此类错误已经造成了备受瞩目的安全漏洞。**
