问题1：
````c
int g (int x, int y) {
	switch(x - y) {
	case 0:
		return x;
	case 4:
		y = y + 1;
		break;
	case 7:
		x = x - 1;
	case 9:
		return x*y;
	case 3:
		y = x + 9;
	default:
		return y - x;
	}
	return y;
}
````
g(3,0)的值是多少？

````spoiler
9

初始：`x = 3, y = 0`
`switch(x - y)` 即 `switch(3)`，匹配 `case 3`执行 `case 3:` 中的 `y = x + 9;`  
所以 `y = 3 + 9 = 12`
`case 3` 后面没有 `break`，会继续向下执行 `default:`
执行 `default:` 中的 `return y - x;`  
即 `return 12 - 3 = 9`
````
