
## 问题 1
作业概述

这次作业让你有机会开发自己的**算法**，并让其他人执行它，从而给你关于其**正确性**和**具体性**的反馈。

你将编写一个算法，对温度数据**从小到大**排序。为此，你将完成**七步**中的前四步。

### 数据介绍
NOAA 的国家环境信息中心收集全球气候数据，并汇总这些数据以提供有关气候趋势和变率的信息。他们提供的一项产品是**月度区域分析**。下表给出了 2017 年 1 月按大洲划分的“异常值”数据。“异常值”是指该值与 1910–2000 年平均温度之间的温差。

| 大洲 | 异常值（C） |
|---|---|
| North America | 3.18 |
| South America | 1.36 |
| Europe | -0.12 |
| Africa | 0.53 |
| Asia | 1.92 |
| Oceania | 0.98 |

来源：  
https://www.ncdc.noaa.gov/sotc/global-regions/201701

### 作业任务
你的任务是开发一个算法，对类似这样的数据**从小到大**排序。具体来说，给定一个包含 N 个十进制值的**未排序集合**，你的算法应将其排序，给出排序后的数据。对于 N = 6 的这组数据，你的算法应产生：

-0.12  
0.53  
0.98  
1.36  
1.92  
3.18

### 第 1 步：手工完成一个例子
取这组值，手工排序。用对你来说最自然的方式排序。不要研究排序算法，也不要试图找出最高效的方法——这不是本次作业的重点。

### 第 2 步：准确写下你做了什么
仔细思考你手工排序时是如何进行的。你比较了哪些值？按什么顺序？你如何知道何时完成？准确写下这些步骤。

### 第 3 步：泛化
查看你在第 2 步中写下的步骤，寻找模式。如果你重复了若干组步骤，如何计算重复次数？如果你在某些条件下交换了某些值，这些条件是什么？为了复用，是否需要命名一些变量？写下你逐步泛化后的算法。

### 第 4 步：测试你的算法
用另一组数据执行你的算法，例如给定数据的子集、你自己编造的数据，或另一个月的气候数据，例如 2017 年 2 月：  
https://www.ncdc.noaa.gov/sotc/global-regions/201702

你的算法对任意 N 都有效吗？你是否考虑了它可能需要处理的**边界情况**，例如 N = 0 或 N = 1？
