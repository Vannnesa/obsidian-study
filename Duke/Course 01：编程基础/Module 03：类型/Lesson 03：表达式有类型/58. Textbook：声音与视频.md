# 声音和视频（Sound and Video）

声音是计算机使用中另一个看似不是数字的常见方面。然而，**声音本质上是一种波形**（waveform），可以很容易地表示为**一系列数字**。对声波最直接的数值表示，就是按周期性间隔记录波的“高度”，形成一系列数字。这些间隔的频率称为**采样率**（sampling rate）（更高的采样率会带来更好的声音质量），通常为 **22 kHz** 或 **44 kHz**——即每秒 22,000 或 44,000 个采样。**立体声**（Stereo）声音只是有 **2 个数字序列**——一个用于左声道，一个用于右声道。与图像一样，有许多典型格式（例如 `WAV`、`AIFF`、`AAC` 等），其中一些是**压缩的**（同样，声音只是数字，所以我们可以对它做数学运算）。

视频（包括本课程中的视频）似乎再次违背了“**一切都是数字**”的规则——然而，到现在，你应该看到数值编码的路径了。**视频是一系列图像**（称为“帧”/frames）**以及相应的声音**。我们已经看到如何将图像和声音编码为数字。最简单的方法是将视频编码为图像序列加上声音。虽然这种方法给了我们一堆数字，但它会非常庞大——一分钟 512 像素 x 256 像素、每秒 32 帧、带 44 kHz 立体声音轨的视频大约需要 **725 兆字节**（几乎 1 GB）。相应地，所有常见的电影格式（例如 `MP4`、`MOV` 等）都会应用**压缩**，不仅对图像和声音本身压缩，而且还表现为**不为所有帧存储完整图像**，而是存储一种**基于前一帧的变化来计算下一帧图像**的方法。下面的视频演示了一些“一切都是数字”的例子。
