选项 创建新标签（1-3）和类型（2-4） 实例化变量 myRect 类型
1. 仅定义标签（rect_t）。
该标签只能与关键字 struct 一起作为前缀使用。 
struct rect_t {
    int left;
    int bottom;
    int right;
    int top;
};
 
int main()
{
    struct rect_t myRect;

    myRect.left = 1;
    ...
}
 struct rect_t
2. 定义标签（rect_tag），
然后定义其类型别名（rect_t）。
struct 声明和 typedef 可以以任意顺序出现。
该标签可以单独与 struct 前缀一起使用。 
struct rect_tag {
    int left;
    int bottom;
    int right;
    int top;
};
typedef struct rect_tag rect_t;
 
int main()
{
    rect_t myRect;

    myRect.left = 1;
    ...
}
 rect_t
3. 第 2 项的缩写形式。
声明和定义出现在同一条语句中。 
typedef struct rect_tag {
    int left;
    int bottom;
    int right;
    int top;
} rect_t;
 
int main()
{
    rect_t myRect;

    myRect.left = 1;
    ...
}
 rect_t
4. 没有标签声明的类型定义。
缺点：struct 不能引用自身。 
typedef struct {
    int left;
    int bottom;
    int right;
    int top;
} rect_t;
 
int main()
{
    rect_t myRect;

    myRect.left = 1;
    ...
}
 rect_t
