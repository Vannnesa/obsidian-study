# Enumerated Types（枚举类型）

程序员可以创建的**最后一种自定义类型**称为**枚举类型**（enumerated type）。枚举类型是**命名常量**，可以提高代码的**可读性**和**正确性**。当你有一类数据，希望用它们的**概念名称**来标记一组值（而不是使用原始数字），并且要么具体的数值**无关紧要**（只要彼此不同即可），要么它们**自然地按顺序递增**时，枚举类型最有用。例如，直到 2011 年，美国国土安全部一直维护一套用颜色编码的恐怖威胁预警级别，用于在包括主要机场在内的各种地点维持更高或更放松的安保状态。从绿色到红色共有五个威胁级别，按严重程度递增。

这五个威胁级别可以记录在一个枚举类型中，我们可以像下面的代码那样自己创建它。

```c
enum threat_level_t {
  LOW,
  GUARDED,
  ELEVATED,
  HIGH,
  SEVERE
};
```

我们以关键字 `enum` 开头，后面跟着新枚举类型的名称，在这个例子中是 `threat_level_t`。各种威胁级别放在大括号中，如上所示。每个级别被分配一个常量值，从 `0` 开始。**枚举名称是常量**——它们不是可赋值的变量。**它们的值在整个程序中不能改变**。表示一个名称是常量的约定是：将名称全部写成大写。然而，可以创建枚举类型的变量，并像平常一样对它们赋值。

因为**枚举类型具有整数值**，所以它们可以用于诸如简单的值比较、`switch` 语句和 `for` 循环等结构中。下面的代码展示了前两者的例子。Enumerated Types 讲座演示了这段代码的执行。

```c
void printThreat(enum threat_level_t threat){
  switch(threat) {
    case LOW:
      printf("Green/Low.\n"); 
      break;
    case GUARDED:
      printf("Blue/Guarded.\n"); 
      break;
    case ELEVATED:
      printf("Yellow/Elevated.\n"); 
```

枚举类型的另一个例子是：如果我们想编写一个程序，经常引用一小类水果：葡萄、苹果、橙子、香蕉和梨。假设我们想把每一种都表示为一个数字（因为我们经常对水果本身使用 `switch` 语句之类的结构），但我们并不真正关心每一种具体用哪个数字表示。我们可以创建一个枚举类型，`enum fruit_t {GRAPE, APPLE, ...};`，然后在代码中到处使用这些常量。
