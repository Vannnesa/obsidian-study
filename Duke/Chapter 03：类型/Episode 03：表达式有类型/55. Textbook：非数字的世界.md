# “非数字”

值得重申：**一切都是数字**。这条规则是理解计算机如何工作的基础，也是编程中最重要的概念之一。对于你在任何编程语言中创建的每个变量，该变量的值——你在所画的每个概念图中“放进盒子”的数据——在计算机中都以**一系列 0 和 1** 存储。对于正整数，这个事实很容易接受：它的十进制表示只需转换为二进制，然后存储在一系列**位**（bits）中。理解负数 and 浮点数（floating point numbers）如何也表示为一系列 0 和 1 可能稍微不那么直接，但仍然符合我们对数字的普遍直觉。

将这条规则扩展到那些看起来不像数字的东西——文字、颜色、图片、歌曲、电影——可能看起来是一个困难得多的概念飞跃。然而，既然我们新认识到计算机**只能对数字进行运算**，我们就必须意识到，所有这些事物也必须是数字——毕竟，我们的计算机经常对它们进行运算。

找到一种方法来编码这些“非数字”数据类型，只不过是提出一种新的约定，把信息编码为位，并解释这些位以表示原始信息。这些新约定并未作为 `C programming language`（C 编程语言）的 `basic data types`（基本数据类型）包含在内（尽管其中一些是 C 以外语言的基本数据类型）。相反，新类型是通过**组合基本类型**来实现程序员的目标而形成的。这些更复杂的类型可能是广泛接受的编程约定（如 `strings`（字符串）的表示），也可能是单个程序员针对其编程任务所做的某种特定处理。
