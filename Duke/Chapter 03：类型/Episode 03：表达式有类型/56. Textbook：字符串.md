# 字符串（Strings）

**字符串**是一个字符序列，以一个称为**空终止符**（null terminator）的特殊字符结尾，该字符可以写作字符字面量 `'\0'`（读作“反斜杠零”），用于**表示字符串的结束**。字符串通过**内存中第一个字符的位置**来引用，然后逐个读取每个 8 位字符，直到检测到 `'\0'`。这个概念的一个简单图示如下所示：
![[Pasted image 20260917123830.png]]

字符串不是 C 中的**基本数据类型**（basic data type），这意味着你不能像使用 `int` 或 `double` 那样简单地声明和使用它们。为了让你稍微了解这个问题的复杂性，考虑一个字符串应该有多大。是否存在一个预定义的位数，应该对应于字符串数据类型？由于每个字符串都有**唯一的字符数量**，这似乎不是一个可以预先做出的选择。事实上，字符串的大小需要**按每个字符串动态确定**。要真正理解如何创建和使用字符串，需要理解 `pointers`（指针）。这也是上面图示故意缺少细节的原因之一——因为我们还没有解释展示如何**声明**（declare）和**实例化**（instantiate）它们所必需的概念。我们将把字符串的进一步讨论推迟到专项课程（specialization）的后面。
