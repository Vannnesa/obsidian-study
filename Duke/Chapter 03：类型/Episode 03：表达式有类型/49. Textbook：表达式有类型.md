在 "表达式 "一课中，我们学习了表达式的求值方法--如果有 a+b*2，那么 b 的当前值将从其方框中读出并乘以 2，然后 a 的值将从其方框中读出并与 b*2 的乘积相加。表达式的求值结果就是总和。

表达式也有类型，由组成表达式的子表达式的类型决定。最简单的表达式是常量，如果是整数常量（如 2 或 46），则其类型为 int；如果是实数常量（如 3.14 或 -8.19），则其类型为 double。如果需要，常量的类型可以通过使用字母后缀来修改（U 表示无符号常量，L 表示 long 常量，f 表示 float 常量）： 3.14f 是浮点类型的常量，99999999999L 是长 int 类型的常量。下一个最简单的表达式类型是变量，它具有所声明的任何类型。

大多数（但不是全部）带有二进制操作符的表达式--即 op e2（如 a + b 或 c * 4）--与其操作数的类型相同。如果 a 和 b 都是 double，那么 a + b 也是 double。同样，如果 c 是 int，那么 c * 4 也是 int（注意 4 是 int）。

函数的类型就是其声明的返回类型。也就是说，如果：
````c
int f(int x, int y){balabala...}
int g(double d, char c){balabala...}
````

那么表达式**f(3, 4) + g(42.6, 'a')** 的类型就是 int。我们可以从**f(3, 4)**和**g(42.6, 'a'**) 都是 int 类型（f 被声明为返回一个 int）这一事实中看出这一点。正如我们刚才所讨论的，将两个 int 相加的结果就是一个 int。
